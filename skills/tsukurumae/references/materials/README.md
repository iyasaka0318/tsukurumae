# 指示書を作るときの材料

ここにある資料は、毎回読み込む規則ではない。要件定義の最後に `TSUKURUMAE_GUIDE.md`（案件専用の指示書）を作るとき、**その案件に関係するところだけ**を選び、文章として指示書に書き写すための材料。

| 資料 | 中身 | 使う場面の例 |
|---|---|---|
| [evidence.md](evidence.md) | 値の確かさの扱い、検証の段階、短い返事の扱い | 試作・測定がある案件全般 |
| [readiness.md](readiness.md) | 作業を確定してよい条件（CAD、通電、デプロイなど） | 本番 CAD、通電、本番環境への反映がある案件 |
| [hardware.md](hardware.md) | 主役の確認、周りの成り立ち、接続した後の寸法、電源、測定 | ハードウェアを含む案件 |
| [software.md](software.md) | 実行環境、リポジトリの外の状態、障害の調べ方、変更とコミット | ソフトウェアを含む案件、組込みファームウェア |
| [rework-catalog.md](rework-catalog.md) | 過去の案件で実際に起きた手戻り | 似た部品・似た作業がある案件 |

書き写すときは、一般論のまま写さず、その案件の部品・環境に合わせた具体的な注意にする。
