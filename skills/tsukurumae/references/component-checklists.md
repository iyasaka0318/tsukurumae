# 部品カテゴリ別：実装論点チェックリスト

Step 3 で「この部品にはこの特徴があるため、設計にこの情報が必要」と判断するためのリスト。
**全部を聞くためのものではない。** 各項目のうち、資料で分かるものは調べ、設計意図に依存するものだけを質問する。
`[聞く]` = 設計意図・手元の実物に依存しやすい、`[調べる]` = 資料で分かることが多い。

---

## MCU ボード（Raspberry Pi Pico 系、ESP32 DevKit、Arduino Nano、Seeed XIAO 等）
- [調べる] バリアント（例：Pico 2 / 2 W / 2 H / 2 WH、H はヘッダー実装済み、W は無線あり）
- [調べる] 外形、取付穴の位置・径、USB コネクタの位置と種類、デバッグ端子の位置
- [聞く] ヘッダーの有無と向き（部品面側 / 裏側）。実装済みの場合、そのまま使うか
- [聞く] 接続方式：ジャンパ線 / 直接はんだ付け / ソケット / 自作基板に実装
- [聞く] ジャンパ線を使う場合、どちら側から挿すか → 挿した状態の高さ
- [聞く] 固定方法：ネジ（M2 等）・スペーサー / 差し込み / 両面テープ / 結束バンド
- [聞く] 完成後も USB を挿すか（書き込み・ログ取得・給電）→ ケーブルを挿すスペースと方向
- [聞く] BOOTSEL / RESET ボタンを押す必要があるか
- 無線付きの場合：アンテナ付近に金属・バッテリー・カーボンを近づけない配置

## IMU・センサモジュール（ICM-42688、BMI088、MPU-6050、気圧、ToF、エンコーダ等）
- [聞く/調べる] 具体的なモジュール（チップ名ではなく基板の販売元・型番）。同じチップでも外形・ピン順・レギュレータの有無が違う
- [聞く] ヘッダーの有無、はんだ付けかジャンパ線か
- [聞く] 基板の向き（どの軸を前にするか、表裏）→ ソフト側の軸変換にも影響
- [聞く] 固定方法、防振（ゲル、ゴム、ダンパ）の要否
- [調べる] インタフェース（I2C / SPI）、電源電圧、ロジックレベル
- [聞く] 配線の逃がし方（振動するケーブルがセンサを揺らさないか）
- 配置：回転中心・重心付近か、モータやESCからの距離（磁気・熱・振動）

## ESC・モータドライバ
- [調べる] 定格電流、入力電圧範囲、プロトコル（PWM / OneShot / DShot）、BEC の有無
- [聞く] 4in1 か単体か、取付方法と位置（アームか中央か）
- [聞く] モータ線の接続（はんだ / バナナコネクタ）、信号線の接続方式
- 放熱：風が当たるか、密閉されないか
- 電源入力に低ESRコンデンサを付けるか

## モータ
- [調べる] 取付穴パターン、軸径、ケーブル長、重量
- [聞く] ケーブルの出口方向（アーム上を通すか内側か）、ケーブル長が足りるか / 延長するか
- 回転方向とプロペラの組み合わせ

## バッテリー
- [調べる] 外形、重量、コネクタ（XT30/XT60/JST-PH 等）、バランスコネクタ
- [聞く] 搭載位置と固定方法（ストラップ、ケース）、交換頻度、機体に載せたまま充電するか
- [聞く] 電源ケーブルとバランスケーブルがどちら側から出るか、どこへ取り回すか
- 重心への影響、着陸・転倒時の保護

## 電源回路（レギュレータ、電源スイッチ、分電）
- [調べる] 入出力電圧、最大電流、外形
- [聞く] 電源スイッチの有無と位置（操作できる場所か）
- 分岐点の位置、太い線と細い線の接続方法
- 逆接続・短絡保護、ヒューズ

## コネクタ・配線全般
- [聞く] 抜き差しが必要な箇所（＝コネクタ化）と、固定でよい箇所（＝はんだ付け）
- 挿した状態の奥行き・高さ、抜き差しに指が入るか
- 電線径と許容電流、配線長、結束方法、ストレインリリーフ
- 可動部をまたぐ配線の扱い

## 3D プリント部品
- [聞く] プリンタの造形サイズ、材料（PLA / PETG / ABS / TPU）、ノズル径
- 寸法公差（穴は小さめに出がち）、ネジの留め方（タップ切り / ヒートインサート / ナット埋め込み）
- 造形方向と強度（積層方向に割れやすい）、サポートの要否
- 発熱部品（ESC・レギュレータ・モータ）に近い場合の耐熱

## 倒立振子・ロボット固有
- [聞く] 車輪・モータ・エンコーダの取付と軸の支持方法
- 重心高さ（制御のしやすさに直結）、転倒時の保護
- 配線が回転部と干渉しないか
