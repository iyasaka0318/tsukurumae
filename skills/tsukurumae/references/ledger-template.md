# 開発台帳（Hardware Ledger）テンプレート

会話中の情報を分類して管理するための書式。ステップの区切り・Gate 判定時・ユーザーが求めたときに提示する。
ファイルを書ける環境では `HARDWARE_LEDGER.md` としてプロジェクトに保存し、更新し続ける。

## 運用のコツ
- ID を振ると、会話で「Q3 の回答は…」と参照しやすい。
- 仮定は確認されたら Known へ移す。決定を変えたら理由を残す。
- 毎ターン全体を出さない。変更点だけを示し、区切りで全体を出す。
