# 台帳の書式

プロジェクトのルートに `TSUKURUMAE_LEDGER.md` として置く。会話をまたいで状態を引き継ぐためのもの。

## 運用

- 案件の最初に作る。既にあれば読んでから始める。
- 更新するのは、決定・仮定・質問の答え・試験結果・作業の状態が変わったとき。
- 各項目に ID を振る（D1、A3、Q5 など）。会話では「Q3 の答えは…」と参照できる。ID は種類ごとに連番にし、追記するときも表の末尾に順に足す。
- 仮定が確かめられたら「事実」へ移し、出典を書く。決定を変えたら、理由と日付を残す。
- 毎ターン全文を見せない。変わった項目だけを伝える。
- 長くなったら、終わった試験記録を `TSUKURUMAE_LOG.md` などへ移す。
