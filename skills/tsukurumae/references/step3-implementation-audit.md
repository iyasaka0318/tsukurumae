# Step 3：実装条件監査 → 設計（Design Input Freeze）

## 目的
部品構成が決まったあと、**その部品を実際に物理的に組み付けられる状態まで情報を詰める**。
この監査が終わる前に CAD・回路図・配線図を生成しない。

## 手順

### 3-1. 部品ごとに「実装状態」を特定する
型番から、設計に効く特徴を導く。商品名だけでは足りない。

1. **バリアントを特定する**：例 Pico 2 / Pico 2 W / Pico 2 H / Pico 2 WH。H 系はピンヘッダー実装済み、W 系は無線モジュール付き（アンテナ周辺に金属を近づけない配慮が要る）。ブレイクアウト基板はメーカー（Adafruit / SparkFun / 無名品）で外形・穴位置・ピン順が違う。
2. **資料で分かることを調べる**：外形寸法、厚み、取付穴の位置と径、コネクタの位置と向き、ヘッダーピッチ、重量、部品面の最大高さ。調べられない場合は「仮定」として明示し、ユーザーに実測を依頼する項目に入れる。
3. **設計意図に依存することを質問する**（[component-checklists.md](component-checklists.md) を使う）。

### 3-2. 4 つの観点で監査する
各部品と、部品同士の関係について確認する。全部を聞くのではなく、**後から判明すると形状・配置が変わるもの**を優先する。

**機械的条件**
外形、基板寸法、厚み、ピンヘッダー高さ、コネクタ突出量、ケーブル差込量（挿した状態の高さ・奥行き）、ケーブル曲げ半径、ネジ穴・ネジ径・ネジ頭・ナット・スペーサー・ワッシャ、固定方法、必要クリアランス、干渉、組立順序、工具（ドライバ・はんだごて）のアクセス、交換性・整備性。

**電装条件**
コネクタ種類、配線方式（はんだ付け / ジャンパ線 / コネクタ）、配線方向、電線径、ピンヘッダー、電源分岐の場所、信号線と動力線の分離、GND、ノイズ源との距離、信号レベル。

**運用条件**
完成後も USB を挿すか、ファームウェア書き込み方法、デバッグ時のアクセス（シリアル、LED、ボタン）、バッテリー交換・充電方法、電源スイッチの位置、部品・センサ交換の必要性、コネクタ抜き差しの頻度。

**配線・伝送条件**
ケーブルがどちら側から出るか、コネクタの向き、配線経路と長さ、内部を通すか外を通すか、断線しやすい箇所（可動部・振動部・鋭い角）、可動部との干渉、ノイズ源（モータ・ESC・動力線）からの距離。

### 3-3. 高さ方向（スタック）を必ず確認する
手戻りが特に多いのは高さ方向。部品ごとに次を足し合わせる:

```
基板厚 + 部品面の最大高さ + ヘッダー高さ（上/下） + 挿したコネクタ/ジャンパ線の高さ + ケーブルの曲げ余裕 + 固定具（スペーサー・ナット）
```

ジャンパ線（デュポン）を挿す場合、ハウジングとケーブルの曲げで基板上にかなりの高さを取られる。具体値はジャンパ線の種類・曲げ方で変わるため、仮定値を置いたうえでユーザーに実測を依頼する。

### 3-4. 「調べる」と「聞く」を分ける
質問前に各項目を振り分ける:

| 種類 | 例 | 扱い |
|---|---|---|
| 資料で分かる | 外形、穴位置、コネクタ位置、重量、ピン配置 | AI が調べる（不可なら仮定と明示） |
| ユーザーの手元にしかない | 実物の状態（ヘッダーはんだ済みか）、手持ちケーブルの長さ、実測値 | ユーザーに確認・実測依頼 |
| 設計意図 | ヘッダーの向き、ケーブルの出口、USB アクセスの要否、取り外し可能にするか | ユーザーに質問（推奨案付き） |
| 後で決めてよい | 色、細かな面取り、ロゴ | 聞かずに仮置き |

### 3-5. Design Input Freeze 判定
設計を始める前に、AI 自身が以下の表を作って監査する。

| 部品 | 実装状態 | 固定方法 | 接続方式・向き | ケーブル出口 | 必要高さ/クリアランス | アクセス要件 | 状態 |
|---|---|---|---|---|---|---|---|
| 例: Pico 2 WH | ヘッダー実装済 | M2 ×4 + スペーサー | ジャンパ線、上向き | 右側面 | 仮定 xx mm（要実測） | USB 常時アクセス | 決定/仮定/未回答 |

- 形状・配置を大きく変える項目に「未回答」が残っていれば **保留**。
- 後から変えても形状に影響が小さい項目は仮置きで **通過** してよい。その場合、仮置き内容を設計物に注記する（例：「ジャンパ線高さ 15mm 仮定、実測で要修正」）。

### 3-6. 設計を出力するとき
Gate 3 を通過したら CAD・回路・配線・コードを作る。出力には次を添える:
- 採用した前提（台帳の決定・仮定の要点）
- 寸法のうち資料由来のものと仮定値の区別
- 試作で確認してほしい点（Step 4 のチェック項目）
- パラメトリックにできる環境なら、仮定値（クリアランス、ヘッダー高さ等）を変数にして後で直しやすくする

## Gate 3 チェック
- [ ] 全主要部品のバリアント・実装状態が特定されている
- [ ] 各部品の固定方法、接続方式、ケーブル出口が決まっている
- [ ] 高さ方向のスタックが計算されている（仮定値は明示）
- [ ] USB・バッテリー・スイッチ等の運用アクセス要件が決まっている
- [ ] 動力線と信号線の経路、ノイズ源との距離が考慮されている
- [ ] 組立順序が成立する（締められないネジ、挿せないコネクタがない）
- [ ] 残る未回答は形状・配置に大きな影響がないものだけ
