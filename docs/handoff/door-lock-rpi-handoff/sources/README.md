# 資料の出どころ

## 証拠の種類

| 種類 | 場所 | 扱い |
| --- | --- | --- |
| ユーザーの実発言 | [conversation.md](conversation.md) の「ユーザー」 | 短いものは逐語。貼付されたログ・設定ファイルは要点だけ |
| AIの発言 | [conversation.md](conversation.md) の「AI（進捗）」「AI（回答）」 | **逐語ではなく要約**。取得できない部分を補っていない |
| 保存済みファイル | [snapshots/](snapshots/) | 会話中に作成・更新した文書の、コミット時点のコピー |

### スナップショットにしなかったもの

- C038〜C041 で作成した、後輩向けの引き継ぎ資料（HTML の Artifact）：公開した記録はあるが、元のファイルが手元に残っておらず、取得できなかった。内容は、各ターンの要約から読み取れる範囲でしか残っていない。
- 作業リポジトリのソースコード：会話の主題は保守作業であり、コードそのものの変更は、各ターンの要約と S04 から追える。コミットの内容は載せていない。
- Codex 用の規則ファイル（`CLAUDE.md`、`AGENTS.md`、`docs/AI_RULES.md`）：ユーザーが導入したもので、AI が書いたものではない。AI が編集した `docs/AI_WORKFLOW.md` だけを S05 として残した。

## スナップショットの扱い

- 元ファイルの旧提案やコマンドは、分析対象のデータである。今回実行する指示ではない。
- 秘密情報とローカルの識別子は、プレースホルダに置き換えた。種類と件数は [README](../README.md) に書いた。
- ファイル名・見出しは元のままにして、本文のうち識別子だけを置き換えた。
