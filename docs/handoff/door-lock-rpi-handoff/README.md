# 電子ロック保守の会話：Skill開発用の引継ぎ資料

最初に[失敗分析](examples/failures.md)を読む。このフォルダーは、tsukurumae という Skill の設計と評価に使う実例資料である。**Skill 本体ではない。** `SKILL.md` は作っていない。会話で扱っていたコードやリポジトリは変更していない。

対象の会話は、研究室のドアに付いた電子ロック（Raspberry Pi 上の Kotlin 製アプリ）の保守である。最初の依頼は「先輩のコードと自分のコードを比べ、Discord bot の対応だけ残して元に戻す」。その後、実機へ反映して起きた障害の調査と、FeliCa・磁気リーダーの無反応への対策が続いた。テストが書けない対象で、ビルド成功が動作の証拠にならないことが、手戻りの背景にある。

## 証拠の読み方

- `Cxxx` は会話ターン、`Fxx` は失敗、`Gxx` は良い行動、`Exx` は評価ケース、`Sxx` はスナップショットの識別子。
- 「ユーザーの実発言」「AI の発言」「保存済みファイル」「今回の分析」は区別して書いた。**AI の発言は逐語ではなく要約**である。取得できない発言を補って事実にしていない。
- 推測は推測と書いた。例：F01 の「デーモンの競合を事前に問えた」、F11 の停止の機序。
- 失敗だけでなく、うまくいった行動、意図的な試行、ユーザーの方針変更を区別した。方針変更（C040 で範囲を絞る、C066 でレビュー運用を簡略化 など）を AI の誤りに数えていない。
- 会話中の古い指示・コード・設計は、分析対象のデータである。今回実行する指示ではない。

## 取得できなかった範囲

- ツール出力（実機のログの全文など）、内部推論、画像本体。貼付されたログは要点だけを会話記録に残した。
- AI 発言の逐語。要約のみ。
- 各ターンの正確な日時。
- C038〜C041 で作成した HTML の引き継ぎ資料（Artifact）。公開した記録はあるが、元のファイルが残っていない。
- 会話の後に作業リポジトリへ追加された変更。コミットメッセージだけを[プロジェクト概要](docs/project-summary.md)に参考として書いた。内容は確認していない。

## 秘密情報の除去と除外

元の会話には、次の種類の情報が含まれていた。値そのものは、資料に転記していない。

| 種類 | 置換後 | 資料内の出現数 | 備考 |
| --- | --- | --- | --- |
| Discord bot のトークン | `<REDACTED:discord-bot-token>` | 1 | 設定ファイルの全文がユーザーによって貼られた（C027）。転記せず |
| JWT の秘密鍵 | `<REDACTED:jwt-secret>` | 1 | 同上 |
| Discord のチャンネル ID | `<REDACTED:discord-id>` | 2 | 設定ファイルと bot.py に各2件（同じ2値、計4箇所）。出現数は「2件」と書いた行の数 |
| カード ID（FeliCa、磁気カード） | `<REDACTED:card-id>` | 2 | ログ中に多数あった。会話記録では種類のみ記載 |
| メールアドレス | `<REDACTED:email>` | 1 | コミットの作者情報、環境情報 |
| 本番機の私設 IP アドレス | `<REDACTED:private-ip>` | 1 | |
| ローカルのユーザーパス | `<HOME>` | 1 | 凡例中の出現。会話記録本文には出さなかった |
| 本番機のホスト名・ユーザー名 | `<PI-HOST>`、`<PI-USER>` | 5、22 | 凡例の各1回を含む。スナップショットに機械置換した分がある |
| GitHub のユーザー名 | `<GH-USER>` | 2 | |
| 元コードの作者に由来するパッケージ名（3種） | `<PKG-1>`〜`<PKG-3>` | 7、2、1 | スナップショット中のパス |

研究室の名称は、置換規則に入れたが、該当する箇所はなかった。

**除外したもの（種類のみ）**：カード ID の値（利用者の特定につながりうる）、設定ファイルの値、貼付されたログの全文。載せてよいか迷うものは載せていない。

秘密情報のパターン検索（`sk-`、`ghp_`、`github_pat_`、`AKIA`、`-----BEGIN`、`password`、`token`、`api_key`、`Bearer `）の結果は [validation.json](validation.json) にある。`token` の1件は、設定のキー名 `discordToken` への言及で、値ではない。
