# 研究用倒立ロボットの経緯とレビューからの論点

目的は、同一RP2350上のTinyML推論・共有資源負荷が、制御応答時間と物理的な倒立性能へ与える影響を比較すること。高価な機体を作ること自体は目的ではない。[C014](../sources/conversation.md#c014)、[S04](../sources/snapshots/S04-robot-selection.md)

ユーザーが貼った別レビューは分析対象の資料であり、各数値・提案が独立に検証済みとは扱わない。ここでは何が設計判断に結び付いたかを整理する。

## 選定と設計の流れ

| 段階 | 会話と保存資料から分かること |
| --- | --- |
| 最小構成 | 研究目的、基準倒立性能、必要な測定系からPico 2 WH＋ICM-42688を扱った |
| モーター候補 | 価格・送料・国内入手性を調整し、FIT0450／マルツをユーザーが選択した |
| 手持ち品 | GNB 2S電池、MINI360、抵抗・コンデンサ・ユニバーサル基板・スペーサー等を棚卸し |
| v1〜v4 | ユーザーが貼ったレビューから電源、計測、ログ、配置、USB予約を更新 |
| v5 | モーター系停止時も制御系へ電池給電を継続。試行中USB常時接続を廃止。確認事項がなお残る |

## R01：部品の許容条件と回路全体を合わせる

レビューには、2S電池直結VMとソフトのデューティ制限で構成を簡素化する提案があった。AIはモーター公表動作範囲とPWMピーク電圧の許容根拠を区別し、直結案を採らなかった。[C051](../sources/conversation.md#c051)

v5は固定5V制御系と左右の降圧モーター系、回生吸収の評価計画を持つ。吸収回路の候補・未装着・評価済み省略構成を区別し、構成に応じた電源監視と重量モデルを合わせる。[S11](../sources/snapshots/S11-robot-v5-circuit.md)

**Skillへの論点**：平均値・公称値だけで成立を断定しない。代替案の部品点数・発熱・故障時・満充電／低電圧・電源OFF時を比較する。別レビューの簡素化提案を無検証に実装しない。評価：E16。

## R02：研究の効果を測れる構成になっているか

微小遅延だけで物理性能差が見えない可能性、エンコーダ割り込み負荷の交絡、計時のバス負荷、PWM方式がレビューで挙がった。周期をまたぐ遅延線、PIO、Core0内の計時と外部応答計測、固定条件を仕様へ入れた。[C051〜C052](../sources/conversation.md#c051)、[S10](../sources/snapshots/S10-robot-v5-plan.md)

**Skillへの論点**：目的→比較条件→測定区間→基準性能→部品・実装の順に結ぶ。差が出ない結果も扱う。「転倒＝締切超過」「実測最大値＝全条件WCET保証」へ飛躍しない。評価：E17。

## R03：ログ運用がUSB・電池台・重心へ波及

v3で試行中USB給電が必要となり、プラグと構成B電池台の干渉可能性が指摘された。v4で挿抜・曲げ・固定点を予約し、電池配置と重心を更新した。v5で試行中USB常時接続を廃止したが、書込み・回収時の挿抜予約は維持した。[C053〜C054](../sources/conversation.md#c053)

**Skillへの論点**：USBポートが見えるだけでは十分でない。いつ接続するか、給電の意味、ケーブル外力、プラグ本体、曲げ、固定、他構成との干渉を確認する。運用を変えたら古い予約と説明を更新する。評価：E18。

## R04：給電継続と、ログの保持・回収は別

v5確認で、給電を続けてもリングへ書込み続けると停止直前ログが上書きされること、測定線の外力が残ること、コンデンサや回生で全OFF時に同時0Vにはならないことを指摘した。[C054](../sources/conversation.md#c054)、[S07](../sources/snapshots/S07-robot-v5-review.md)

**Skillへの論点**：全運用経路を考える。通常終了、異常停止、watchdog、再起動、USB回収まで追い、最初の停止理由と末尾データを保持する。電源・ログ・機械の状態を混同しない。評価：E17、E18。

## R05：静的な配置だけでは機体の成立を示せない

レビューで、車輪を含む重心の扱い、モーターの向き、後傾時のエンコーダ側接地、主基板の四隅固定予約、電池位置の構成差が挙がった。[C051〜C052](../sources/conversation.md#c051)

**Skillへの論点**：機械の移動・傾き、支持荷重、配線外力、組立順序まで扱う。仮寸法で得た接地角・重心は実測値にしない。部品を詰めてから固定穴を追加する順序を避ける。

## 到達点

v5の文書・計算・予約空間を確認した段階。基準倒立、電源波形、吸収回路、ログ回収、動的機械干渉は実機未検証。資料の「注文済み」は記載された状態で、注文履歴を今回確認したものではない。趣味用ドローンの回転成功を研究用倒立ロボットの合格として流用しない。
