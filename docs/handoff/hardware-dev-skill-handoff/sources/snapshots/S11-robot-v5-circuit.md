# 倒立ロボット 全体回路案 v5

2026-10-03、外部レビュー反映。FIT0450×2、Pico 2 WH、ICM-42688-P #42688、AE-TB67H450×2、AE-LLCNV-LVC8T245、2S電池。購入候補の資料と端子を照合した接続計画。実機未検証で、電源試験を通してから倒立に使用する。旧SN74LVC245A単体用の配線を置き換える。

## v5の変更

**制御系とモーター系の電源を分離した。** 注文済みのトグル103774は「モーター電源スイッチ」とし、mini360 #2/#3の入力だけを切る。固定5V・Pico・エンコーダ・IMUは電池接続中は動作を続けるため、非常停止してもRAMログが残る。v4のUSB常時接続は廃止した。機体全体の遮断は当面XT30を抜いて行う。MASTER_SW予約位置（現状は取り外し可能な短絡線）へスイッチを入れるかは、研究室の在庫を見て判断する。

## 構成の固定と未装着時

**標準構成Aは左右の吸収回路を装着する計画**。回路方式・部品が未検証なので、製作して単独評価と実機の電源評価を通すまでは「候補」。未装着で使用可という意味ではない。以下の電源図・張り付き監視は構成Aに対応する。

| 構成 | HAS_REGEN_DUMP | GP21/22判定 | モーターARM |
|---|---|---|---|
| A：左右装着、電源試験合格 | true | 吸収OFF／張り付き監視を有効 | 他のARM条件も満たせば許可 |
| 未装着・未評価 | false | 吸収ONと解釈しない。端子はNC、下側4.7kΩでLowに固定 | 禁止。USB/IMU/手回しエンコーダ等の非駆動試験のみ |
| B：吸収省略が電源試験で認められた個体・条件 | false | 張り付き判定を無効、VM電圧監視は継続 | 承認済み電源プロファイルと他のARM条件で許可 |

`HAS_REGEN_DUMP`は物理配線と一致するビルド設定とし、ログへ保存する。Lowを見て自動で「未装着」と判断せず、VMへのジャンパで監視を偽装しない。Bには停止・反転・電流制限・電池残量範囲のVM≤7.2V等の評価記録が必要。設定フラグだけで省略を許可しない。構成や電流上限を変えたら再評価する。重量・電池位置もA/Bで異なる。

## 電源の全体像（構成A）

```text
電池+ → XT30 → 5Aヒューズ → BAT_F
  → MASTER_SW予約位置 [現状は取り外し可能な短絡線。全OFFはXT30を抜く]
  → BAT_L 分岐
      ├ 制御系 [電池接続中は常時ON]
      │   AE-LXDC55-5V I → O = V5
      │                      ├ 左右エンコーダ V+
      │                      ├ レベル変換 VA (1,24)
      │                      └ 1N5819 → Pico VSYS（帯側がVSYS）
      ├ 電池電圧分圧 → GP26
      └ モーター電源スイッチ（トグル103774） → BAT_M
            ├ mini360 #2 IN+ [左専用]
            │    OUT+ → SB340LS → VM_L
            │                      ├ 左ドライバー VM
            │                      ├ 470µF + 104 → GND
            │                      ├ 左回生吸収回路 → GND
            │                      └ 分圧 → GP27
            └ mini360 #3 IN+ [右専用]
                 OUT+ → SB340LS → VM_R
                                   ├ 右ドライバー VM
                                   ├ 470µF + 104 → GND
                                   ├ 右回生吸収回路 → GND
                                   └ 分圧 → GP28

電池- → GND分岐
          ├ 固定5V基板G、およびmini360 #2/#3 IN-/OUT-
          ├ 左ドライバーGND、左RS下端、左吸収回路GND
          ├ 右ドライバーGND、右RS下端、右吸収回路GND
          └ 制御系GND [Pico、変換基板、IMU、エンコーダ]

Pico 3V3(OUT) → IMU VDD/VDDIO、変換VB、左右VREF抵抗体の上端
```

**MASTER_SWは電池・ヒューズの直後、すべての負荷より上流に置く。** こうすると「制御系だけOFFでモーター系がON」という状態（無給電のPicoへVM分圧やドレイン監視の電圧がかかる状態）が配線上起こらない。その代わりMASTER_SWには機体全体の電流が流れるので、追加するスイッチは直流で5A（ヒューズ定格）以上の定格を資料で確認する。定格が分からない部品と、押している間だけONになるボタンは使わない。押すたびにON/OFFが保持されるオルタネート式は、定格を満たせば候補にできる。該当品がなければ同じトグル103774（120円）を追加する。

モーター電源スイッチに流れるのは左右モーター系の電流だけ（1A制限×2で電池側約2Aの見込み）。制御系の消費電流は未測定（数十mA程度の見込み）。電池をつないだままにすると、モーター電源OFFでも電池は減り続け、ソフトでは電源を切れない。リポ電池の過放電を避けるため、各セッションの最後に必ずXT30を抜く。

出力のプラス同士は接続しない。モーター電流のGND帰路をPicoやIMUの細い線へ流さない。電力配線は基板ランドの連続はんだだけに頼らず、絶縁された太い線で分岐する。ドライバーRSの下端とVREFのGNDはドライバー近傍で接続する。

**電池直結VMは今回は採用しない。** FIT0450の公表動作範囲は3～7.5V、手持ち電池は満充電8.4V。デューティ上限6/VBATで平均を抑えても、8.4Vのパルスをメーカーが許容したことにはならない。また、満充電時や主スイッチOFF時の回生を電池が常に受けられるとも言えない。直結案へ変更するには、PWM許容条件のメーカー確認と電池・遮断時の回生評価が別途必要。

SB340LSは帯側をVMに接続する。ダイオードは帰還ループ外なのでVMは負荷で変わる。**無負荷VMを6.20V以下に制限し、負荷時は5.8～6.0Vを狙う**。負荷時6.0Vのために無負荷上限を越えて調整しない。実験中のVMをログに残し、電源試験で5.7V以上を維持できない個体は使わない。これは安定化精度の保証ではなく、手持ち電源を利用する試作の運用範囲。

吸収回路はON=6.70±0.05V、OFF=6.60±0.05Vを実測調整し、温まった状態でも確認する。無負荷VM上限6.20Vに対し、解除電圧の下限6.55Vまで最低0.35Vの差を設ける。MOSFETドレインの監視を追加する（下記）。張り付き時にソフト停止しても吸収抵抗への給電は続くため、モーター電源スイッチのOFFが必要（v5ではこれで吸収回路への給電が止まり、制御系とログは残る）。**回路と温度の試験が終わるまで、6V電源＋吸収回路は未検証案であり、倒立へ投入しない。** 詳細は回生検討案を参照。

5V系はAE-LXDC55-5Vを標準採用する。基板表示のI=BAT_L、G=GND、O=V5。可変出力への加工はしない。入力6～14V、固定5V、最大1.5A。半固定の誤調整をなくす変更であり、故障時まで出力5.5V以下を保証する独立過電圧保護ではない。初回組立時に無負荷・負荷の出力を測る。

モーター電源スイッチ103774は28VDC/5Aを販売仕様とメーカー図面で確認済み。5Aヒューズと定格電流は一致するが、ヒューズの時間電流特性との保護協調を証明したわけではない。実負荷・突入・遮断試験を行う。ON-ON品の中央端子と片側外端子を使用し、もう一方を未接続・絶縁する。ヒューズは電池コネクタの近く、MASTER_SW予約位置とモーター電源スイッチより前に置く。5Aは配線の許容電流と溶断特性を照合する候補であり、瞬時に5Aで切れる部品ではない。ドライバーの電流制限を代替しない。

USB給電だけではエンコーダ5VとモーターVMは供給されない（書込み・単体デバッグ用）。電池接続中にUSBを挿すと、VSYSへは固定5V（1N5819経由）とUSB（Pico基板上のダイオード経由）の両方から給電されるが、ダイオードで分離されるので問題ない。VBUSへ外部5Vを入れない。

## 左右ドライバー

| 基板端子 | 左 | 右 |
|---|---|---|
| 1 GND | 共通GND | 共通GND |
| 2 IN2 | GP7 | GP9 |
| 3 IN1 | GP6 | GP8 |
| 4 VREF | 左調整回路 | 右調整回路 |
| 5 VM | VM_L | VM_R |
| 6 OUT1 | 左モーター端子 | 右モーター端子 |
| 7 RS | 左0.22Ω → GND | 右0.22Ω → GND |
| 8 OUT2 | 左モーターのもう一方 | 右モーターのもう一方 |

各IN1/IN2に10kΩプルダウン。VREFは3.3V–10kΩ半固定–GNDの中点から取り、VREF–GNDへ100kΩ。抵抗体の端子と中点はテスターで確認する。0.22Ω時 `Ilimit = VREF/(10×0.22)`。最初はVREF=2.2V、公称1A。3.3Vなら1.5Aだが、電源・温度・回生評価を終えずに増やさない。抵抗5Wは余裕であり、5Wを使い切る電流で動かす意味ではない。

GP6/7はPWM slice3、GP8/9はslice4。両スライスを20kHzにそろえ、同時に開始して位相を合わせる。外部PWMは**駆動／ブレーキ**に固定する。

| 指令 | IN1 | IN2 | PWMの駆動割合 |
|---|---|---|---|
| 正方向 | H固定 | ブレーキ区間H／駆動区間L | IN2のLow割合=d |
| 逆方向 | ブレーキ区間H／駆動区間L | H固定 | IN1のLow割合=d |
| ARM中のゼロ指令 | H | H | ブレーキ |
| 未ARM／異常停止 | L | L | Hi-Z、コースト |

各sliceのA/B比較値は `pwm_set_both_levels` 等で1回の32bit書込みにまとめ、正逆切替時に片側だけが先に変わることを避ける。PWM比較値と駆動デューティdは反対になるため、入力波形を確認してからモーターを接続する。停止を単に「PWM=0」と書かない。LLが約1ms（標準）続くとスタンバイ、復帰は最大30µs。ARM時はHHで復帰し50µs以上待ってから制御を開始し、比較試験の測定区間に復帰を含めない。ソフト異常停止ではPWM機能を解除して両INをLowへ固定する。

外部PWMのブレーキ区間はスロー減衰だが、**内部の定電流制御はMixed Decay（fast/slow）**であり、電流制限作動時の回生は残る。不感帯時間や許容差もあるので、公称1Aを瞬時電流・回生電流の絶対上限とは扱わない。停止・反転・電流制限時のVMを測る。左右の回転・エンコーダ符号は、車体が前進した時に両方正となるよう実機で合わせる。モーターOUT2を電池GNDへ直接つながない。

## エンコーダの変換基板

以下は**AE-LLCNV-LVC8T245の外部24端子番号**。搭載ICそのものの端子図と混同しない。

```text
VA  (1,24) ← V5 = 5V
VB  (23)   ← Pico 3.3V
GND (12,13,22) → GND
DIR (3)    → 外部配線なし [基板上10kΩでVAへプルアップ、A→B]
/OE (2)    → GND [有効]

左A → A1 (4) → B1 (21) → GP2
左B → A2 (5) → B2 (20) → GP3
右A → A3 (6) → B3 (19) → GP4
右B → A4 (7) → B4 (18) → GP5
未使用A5～A8 (8～11) → GND
未使用B5～B8 (17～14) → 未接続
```

基板のDIRと/OEにはVAへのプルアップがある。/OEを放置すると出力無効になる。基板には各電源のコンデンサが実装済み。エンコーダ側の電源近くに手持ち104を各1個追加する。

FIT0450のモーター端子2本と、エンコーダ電源/GND/A/Bの4本を区別する。Wikiに端子順に関する指摘が掲載されているため、数字や線色だけで配線しない。届いた基板の文字、製品リビジョン、導通、低電流試験を照合する。A/B出力レベルや駆動方式が不明なら波形を測る。5Vで駆動する候補だが、信号Highが変換基板の5V側入力条件を満たすかも確認する。

エンコーダは**PIO0のSM0/SM1で左右のA/Bを4逓倍カウント**する。車輪エッジごとのCPU割り込みを使わない。公式quadrature_encoder例を出発点にSMクロックを分周なし（clkdiv=1、clk_sys=150MHz）に固定し、Core0が制御周期ごとに各1回読み出す。公式例は非ブロッキングpushでカウントを続ける一方、CPU側get_countは古いFIFOを排出して新しいサンプルを待つ。待機を無制限に流用せず、PIOループ最悪10cycleは約0.067µsで、CPUのFIFO排出・共有バス待ちは別に測る。通常取得時間は実測で定め、停止を検出する取得上限は1制御周期（1ms）とする。超過は取得異常と制御締切超過を区別して記録し、停止する。内部プルアップのサンプル設定も、そのまま流用しない。

GP2～5に**外付け4.7kΩプルダウン各1本**、内部プルは無効。旧RP2350 A2のE9とUSBのみ給電で変換出力がHi-Zになる条件を考慮する。A4で修正済みでも同じ配線を使う。PIO読み出し・時刻記録の処理量は全条件で固定する。左右サンプルの時刻差を記録し、完全同時取得と主張しない。

公式の「8 pulse」「出力軸960」と片相立上り／4逓倍は区別し、車輪を実際に1回転してcounts/revを記録する。960が片相周期なら4逓倍・160rpmは1輪約10.2kカウント/秒になるが、実機の定義確認前の仮計算である。

## 電圧監視・操作・研究用端子

各電圧から20kΩ（10kΩ2本直列でも可）–10kΩの分圧を作り、分圧点からADCへ10kΩ直列、ADC側に104をGNDへ接続する。BAT_L→GP26、VM_L→GP27、VM_R→GP28。8.4Vが約2.8Vになる。抵抗比誤差とADC誤差をテスターで校正する。このRCの公称時定数は `(20kΩ||10kΩ + 10kΩ)×0.1µF ≈1.67ms`。停止表の「2ms継続」はフィルタ後のADC値が閾値を超えた時間であり、実電圧の変化から2msで止まる保証ではない。ステップ応答、サンプリング位相、タスク遅延を含めて測る。例えば電池8.4→6.5Vでは公称RCだけで7.0Vを下回るまで約2.2ms、そこから2ms判定＋サンプル待ちが加わる。VMのµsピークは吸収回路と外部波形測定で扱う。GP26～28は `adc_gpio_init` でデジタル入力バッファを無効にする。ADCは低速監視用で、µsの過電圧検証にはオシロスコープを使う。電圧監視線は切り離せる端子にし、Pico無給電で外部電圧だけを印加する試験を避ける。直列抵抗だけで無給電GPIOの過電圧保護が保証されるとは扱わない。

| GPIO | 用途 |
|---|---|
| GP10 | CONTROL_ACTIVE：制御開始でHigh、PWM設定完了でLow |
| GP11 | DEADLINE_MISS：試験中1回でも発生したらHigh、集計値はログ |
| GP12 | CORE1_ACTIVE：対抗負荷・推論が実行中ならHigh |
| GP13 | TRIAL_SYNC：試験開始同期信号 |
| GP14 | ARM/STARTボタン → GND、プルアップ |
| GP15 | STOPボタン → GND、プルアップ（ソフト停止） |
| GP20 | IMU INT1。測定器も分岐してDRDY→PWM完了時間を測る |
| GP21/22 | 左／右吸収MOSFETのドレイン監視（Low=吸収ON、VM有効時のみ判定） |
| GP26/27/28 | BAT_L / VM_L / VM_R 電圧監視 |

ARM/STOPは上側面へ移設し、共通GND＋GP14＋GP15の3線で主基板の3P端子へ接続する。GPIO表は物理ピン番号ではない。測定ヘッダーにGND、DRDY、CONTROL_ACTIVE、CORE1_ACTIVE、SYNC、MISSを出す。ロジックアナライザで電力電圧を測らない。電流検出RSは制限用で、今回ADCへ直接つながない。

吸収MOSFETのDから6.8kΩ–4.7kΩの分圧を作り、分圧点をGP21/GP22へ接続する。ドレインはOFF時VM、ON時ほぼGNDになる。VM=7.2VでGPIOは約2.94V。両抵抗±5%を仮定すると、VM5.7V時Highの下限は約2.19V、VM7.2V時の上限は約3.12Vで、3.3V給電時のVIH最小2.0Vを満たす計算。分圧下側4.7kΩはHi-Z時の外付けプルダウンも兼ねる。OUT/ゲートへ分圧を追加するとゲート電圧とヒステリシスが変わるため、**ゲートには監視分圧を追加しない**。この監視線は保護対象VMの設計上限内を前提とし、任意の電源故障でGPIOを保護する回路ではない。Pico無給電で監視線だけ通電しない。

### 停止条件（試作開始値）

電圧はテスターで校正し、1msごとに監視する。1ms監視を含む同一処理を全実験条件で実行する。数値は電源試験後に版を更新して固定する。電池のメーカー放電下限やセル個別保護を代替する値ではない。

| 条件 | 動作 |
|---|---|
| ARM | 電池7.8～8.45V（校正後の測定値）、左右VM5.8～6.2V、IMU正常、構成Aは吸収OFFが100ms継続、承認済み電源プロファイル、姿勢±3°以内、手動ARM |
| 電池7.4V未満が100ms継続 | 試験終了、LL固定、再ARM禁止 |
| フィルタ後の電池7.0V未満が2ms継続 | 異常停止（RC遅れを含むため即時とは呼ばない） |
| どちらかのVMが5.7V未満10ms、または7.0V超2ms | 異常停止。7.2V波形上限の保護をADCだけに任せない。左右同時の低下は「モーター電源OFFの可能性」、片側だけの低下は「電源・配線異常」として停止理由を分ける |
| 吸収ONが250ms継続 | 構成Aのみ：張り付き／過大回生としてLL停止。停止後100msでOFFにならなければモーター電源スイッチを直ちに切る |
| IMUのDRDYが3ms来ない、PIO取得1ms超、傾き±8°超（開始値、実接地角からさらに調整） | 異常停止 |
| 制御完了から4ms経過 | ハードウェアwatchdogでリセット。更新はCore0制御完了時のみ、Core1から更新しない |

ARMの8.45V上限はADCの残余誤差を許容するためで、電池を8.45Vまで充電してよいという指示ではない。手持ち電池の運用上限は8.4Vを維持し、テスターで確認する。設定上限の余裕でADC校正を省略しない。

傾角停止は暫定±8°。荷重・タイヤ変形・ガード変形を含めた最初の接地角θminを実測し、`min(10°, θmin−2°)`以下へ設定する。LL停止後も慣性と重力で倒れるので、停止閾値だけで接地を防がず、前後バンパーを必須とする。

STOPボタンはソフト停止。異常停止はラッチし自動復帰しない。リセット中はINの10kΩプルダウンでLLとなることを実機確認する。CPU停止中もPWMがwatchdog発火まで継続することを試験する。**ソフト停止では張り付いた抵抗や降圧電源への給電を切れない。** この案は操作者がモーター電源スイッチを切れる監督下の短時間試験用で、自律運転の電源遮断機能を備えた設計ではない。張り付き検出後のソフト停止だけで熱問題が解決したと扱わない。

セル電圧とバランスは試験前後に確認し、パック電圧だけで一方のセル低下を判定しない。モーター電源スイッチOFFでVM_L/VM_Rだけが落ち、Pico・エンコーダ5V・IMUは動作を続けることを、USBなしで確認する。

### 計測・watchdogの実装条件

全条件でCYW43未初期化、オンボードLEDも使わない。Core0のISR入口→タスク開始→PWM書込み区間は**CYCCNTを主計測**とする。ただしISR入口ではDRDYエッジ自体を捕捉できず、割り込み受付遅延は外部GPIO計測で補う。共通タイマーはコア間・長時間の対応と出力スケジューリングへ使う。別コアCYCCNTの直接比較をしない。sleep中のカウント挙動も確認する。

GP10はPWM書込み完了で、20kHzの次wrapへの反映には最大約50µsの差がある。実IN波形も測り、書込み時刻をそのまま物理反映時刻としない。

watchdog時のログは専用NOLOAD領域へ置き、起動初期化から除外する。通常Flash起動ではscratch0～3に実験情報を置き、scratch4～7をSDK/Bootrom用に残す。特殊起動のscratch2/3と混在させない。再起動直後はLLのままログ回収状態へ入る。電源断後の保持は保証しない。詳しいメモリ予算、途中書込みの扱い、故障注入試験は [計測とログ実装仕様v5](倒立ロボット_計測とログ実装仕様_v5.md)。現時点では実装・実機保持試験は未実施。


## 電源分離の運用とログ回収

### 標準手順

1. モーター電源スイッチがOFFであることを確認してから電池（XT30）を接続する。Picoが起動し、IN1/IN2はLLのまま。
2. 電池電圧・セル電圧・構成設定（`HAS_REGEN_DUMP`）を確認する。試行中はUSB非接続を標準条件とする。
3. モーター電源スイッチをONにし、VM_L/VM_Rが5.8～6.2Vで安定したことを確認して手動ARMする。
4. 試行終了または異常時は、STOP（ソフト停止）またはモーター電源スイッチOFFで止める。どちらでもPicoは動作を続け、RAMログは残る。
5. 機体を静置し、USBを接続してログを回収する。保存を確認するまで電池を抜かない。
6. セッション終了時は、モーター電源スイッチOFF → USBを外す → XT30を抜く。

モーター電源スイッチは、LL（未ARM・異常停止）の状態でのみONにする。ARM中に入れ直さない。試行中にモーター電源をOFFにすると、VM低下の停止条件で異常停止がラッチされる。VMがない間はIN1/IN2をLLに保ち、無給電のドライバー入力へ電圧をかけ続けない。

USB接続は書込み・デバッグ・ログ回収用。USBを挿したまま行った試行は別条件として記録し、比較データへ混ぜない。USBの挿抜空間は [設計・配置v5](倒立ロボット_設計レビューと配置_v5.md) に従う。

## 組立前の確認

1. 電源分離を確認する：モーター電源スイッチOFFでV5・3.3V・BAT_Lが出てVM_L/VM_Rが0V付近、ONでVMが立ち上がること。構成A/B設定と実配線を照合し、未装着・未評価ならモーターARMできないことを確認。無負荷で5V、左右VM、VREF、変換VA/VB、3.3Vを確認。モーターを外して変換出力が3.3V側になることを確認。
2. 構成Aでは回生吸収回路を電流制限付き電源で単独評価し、開始/解除電圧、ゲート動作、抵抗温度を記録。
3. 車輪を浮かせ、片側ずつ低PWM、エンコーダ符号、停止・反転時のVM波形を確認。
4. 1A制限で電圧低下・mini360/ドライバー温度を確認。左右同時、電池残量が少ない状態も試す。
5. 実験の反転条件でVMが7.2V以下に収まることを確認する設計目標。超えるなら吸収能力・容量・配線を変更する。モーター公称動作上限7.5Vに対して余裕を設けた目標で、未達のまま倒立させない。
