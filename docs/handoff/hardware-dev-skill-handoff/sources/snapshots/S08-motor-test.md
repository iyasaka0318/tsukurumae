## 使用配線とプログラム

配線は以下を案内した構成で試験した。信号線に外付け10kΩ抵抗や分岐は使用せず、GP4の内蔵プルダウンを有効にした。

```text
バッテリー ＋／－ → ESC主電源 ＋／－
ESC V／G         → MINI360 IN＋／IN－
MINI360 OUT＋    → Pico VSYS（物理39番）
MINI360 OUT－    → Pico GND （物理38番）
Pico GP4（物理6番） → ESC信号「1」
ESCチャンネル1の3相出力 → モーターの3本の線

開始入力：Pico GP14（物理19番）―ジャンパ線―GND（物理18番）
待機時は未接続。開始時は接続を保持。離すと停止指令。
```

回転を確認したファイル：`esc_test_pico_w_1200us.uf2`。同時点の`esc_test_pico_w.uf2`も同じ内容。

SHA-256：`11d1e0038c6758199f7f192880b2eb31dd8bcb6f29e25a7ee68e26e34409740a`

| プログラムの設定 | 値 |
| --- | --- |
| PWM | 公称50Hz、停止指令1000µs |
| 起動待機 | 5秒＋開始入力が開放されていることを確認。操作手順では6秒待機 |
| 開始 | 開始入力をGNDへ1秒連続接続 |
| 回転指令 | 1010µsから1200µsまで約1.9秒で段階的に増加 |
| 停止 | 開始線を離すと停止指令。回転指令開始から最大3秒で停止指令へ戻る |

上の数値はプログラムの設定値。実機波形や機械的な停止時間を測定した値ではない。

## 不具合と修正

旧版は回転指令の上限が1100µsで、モーターが回らなかった。[BLHeli_S公式ソース](https://github.com/bitdump/BLHeli/blob/master/BLHeli_S%20SiLabs/BLHeli_S.asm)の標準最小スロットルは1148µsのため、旧版の上限は標準設定の回転範囲に届いていなかった。

上限だけを1200µsに修正し、同じ配線で回転を確認した。この結果は、旧上限が低すぎたことが原因という判断と整合する。手持ちESCの保存設定と実際の最小始動パルス幅は読み出し／測定していない。

修正版のビルド、開始・停止条件、1200µs上限への到達、3秒上限、再始動条件、タイマー桁あふれのホストテストは成功。UF2のRP2040識別子・boot2 CRC・ベクタ表も検証済み。

今回確認できたのは単体の回転動作まで。推力、負荷電流、温度、連続運転、4モーター同時運転、固定ボードの耐荷重、飛行性能は確認していない。
