# 研究用倒立ロボット：最小構成と選定基準

2026-10-02。添付研究計画を受けた設計方針。設計案v0を補足する。購入確定表ではない。

## 研究目的に合わせた判断

同一RP2350上の制御とTinyML推論について、共有資源への負荷が制御の応答時間・期限超過と物理的な倒立性能にどう影響するかを比較する。高価格部品は必須ではない。推論停止時に十分安定する機体と、比較条件を記録できる測定系を優先する。

資料中の新規性・受賞可能性・参考文献の妥当性は、この部品検討では検証していない。また実験で観測した最大実行時間は、全条件でのWCET上限やハードリアルタイム保証の証明ではない。

## 必要な構成

| 部品 | 最小構成・選定条件 | 今回の扱い |
|---|---|---|
| MCU | RP2350基板1枚。両コアを実験対象とする | 手持ちPico 2 WHを暫定前提。無線は比較実験では停止し条件を固定 |
| IMU | 加速度・ジャイロ、設定可能な出力周期、SPI、データ準備割り込み | Strawberry Linux ICM-42688-P #42688。SPIとINT1を配線 |
| モーター | 同型2個、A/B相エンコーダ付きDCギヤモーター。速度・トルク・拘束電流・出力レベルが分かること | Pololu #5134は仕様確認用の基準候補。価格を含め最終比較する |
| 車輪 | 同型ゴムタイヤ2個、シャフトに確実に適合 | 70mmを比較の出発点。モーター能力と重量次第で小径化する |
| ドライバー | 3.3V制御、左右独立駆動、起動・急反転時の電流に対応する基板 | Pololu DRV8833 #2130は#5134との電流比較が可能。型番だけ同じ廉価基板は同等とみなさない |
| 電源 | 電池・ホルダー・スイッチ、安定したMCU電源、電源電圧を測れる配線 | 電池本数・レギュレーターは重量と電圧範囲を合わせて決定。NiMH5本をPicoへ直結しない |
| 配線・固定 | 小型ユニバーサル基板、固定コネクター、配線保持、ねじ・ナット | 最終実験では抜けやすい接続と基板の揺れを減らす |
| 測定系 | GPIO測定端子、ロジックアナライザーまたはオシロ、テスター | 大学の機材を借りられれば購入不要。時間分解能は測るジッタに合わせて選ぶ |
| 筐体 | PLA、左右対称のモーター固定、剛性のあるIMU台、移設可能な電池台、転倒保護 | 既存Pico試験片の薄いねじ穴周辺は構造部品へそのまま流用しない |

モーターのエンコーダは姿勢推定用IMUの代わりではない。車輪速度・移動量を得て位置の漂流を抑え、左右差や駆動飽和を記録するために用いる。モーター軸側エンコーダではギヤのバックラッシュやタイヤの滑りは直接測れない。

## モーター候補の現状

- Pololu #5134：6V、51.45:1、無負荷420rpm、拘束電流0.67A・拘束トルク0.54kgf cm（メーカー外挿値）、3mm D軸。エンコーダは3.3Vで使用可能。ケーブル別売。仕様の明確さを買う候補で、倒立性能を保証するものではない。
- DFRobot FIT0482：6V、50:1、無負荷310rpm、定格180rpm・0.35kgf cm・170mA、ケーブル付属。公式価格は1個11.90米ドル。安価な代替候補だが、商品ページで拘束電流を確認できていない。定格170mAだけでDRV8833に適合と判断しない。エンコーダのカウント方法も現物確認する。
- 全質量、重心、車輪半径と必要な加速から比較する。拘束トルクを連続使用できるトルクとして計算しない。全質量250〜400g、車輪70mmというv0の仮値は、購入を正当化する確定仕様ではない。

## 部品に起因する疑義を減らす実験

1. Core1を停止または待機させ、倒立継続・電圧・モーター指令の飽和を記録して基準性能を確認する。
2. 同じ機体・電池条件・制御ゲイン・IMU設定で、CPU負荷、メモリー負荷、TinyML推論を順に比較する。最初から学習まで実装しない。
3. 制御周期の根拠と期限を決め、割り込みからPWM更新までの遅延、周期ジッタ、期限超過率を測る。内部計時と外部GPIO測定の測定区間を一致させる。
4. 姿勢のRMS、倒立継続時間、再現可能な外乱からの回復、モーター指令・電源電圧を記録する。時間劣化と転倒の因果関係は結果から検討し、先に断定しない。
5. 通信・ログ収集による干渉も条件化する。制御処理内のprintfを避け、保存後回収する方式でもバッファ書込み負荷は揃える。
6. 試行回数・試験時間・電池状態・床・総質量・重心位置・配線条件を揃えて報告する。必要に応じて側面動画で姿勢の評価を補助する。

## 省けるもの

カメラ、LiDAR、高級サーボ、専用AIアクセラレーター、別マイコンへの推論分担、独自PCB、金属筐体は現段階で不要。外部計測器は制御・推論を代行せず、タイミング測定に使う。
