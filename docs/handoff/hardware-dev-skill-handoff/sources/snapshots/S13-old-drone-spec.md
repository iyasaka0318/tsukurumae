# 145mm クアッドフレーム 設計仕様書（Fusion 360 用）

最終更新：2026-09-14

## 0. この資料の使い方

- この資料は、別の AI や人に渡して Fusion 360 でフレームを作図してもらうための仕様書。
- 寸法はすべて mm。
- 「確定」は変更しない前提。「仮」は後で実測値に置き換える前提なので、必ずユーザーパラメータにしておくこと。
- 作る順番は、**1. 穴径テストピース → 2. 下板 → 3. 上段デッキ → 4. 脚**。
- テストピースの結果で穴径のパラメータを直してから、本番パーツを印刷する。

## 3. Fusion 360 の作業ルール

1. **上方向は Z**：新規デザインの前に「基本設定 → 一般 → デザイン → 既定のモデリング方向」を **Z 上方向** にする。
2. **単位は mm**。
3. **ユーザーパラメータ**：寸法は「修正 → パラメータを変更」に登録し、スケッチ寸法ではパラメータ名を使う。
4. **コンポーネント構成**：ボディではなく、コンポーネントを分けて作る。
   ```
   Frame (最上位)
   ├─ TestCoupon      テストピース
   ├─ BottomPlate     下板（アーム一体）
   ├─ TopDeck         上段デッキ
   ├─ Foot            脚（1 つ作って 4 つに複製）
   └─ Dummies         確認用ダミー（印刷しない）
       ├─ Motor ×4 / PropDisk ×4 / PropLimitRing ×4
       ├─ ESC / Pico / IMU / Battery / Standoff ×4
   ```
5. **原点**：機体中心・下板の下面を原点 (0,0,0) にする。X+ = 右、Y+ = 前、Z+ = 上。
6. **対称形状**：4 つのアームやモーターパッドは、1 つ作ってから XZ 平面・YZ 平面のミラーで増やす（左右前後の対称が崩れないようにするため）。
7. **書き出し**：各コンポーネントを右クリック →「メッシュとして保存」で STL 形式・単位 mm にする。
8. **API スクリプトで作る場合**：Fusion API の内部単位は **cm**。mm の値は 10 で割って渡すこと（例：3mm → 0.3）。ユーザーパラメータは `design.userParameters.add(name, ValueInput.createByString("3 mm"), "mm", "")` のように単位付き文字列で作ると間違えにくい。

## 5. パーツ 1：穴径テストピース（最初に作る）

**目的**：FDM プリンタで刷った穴は、データより 0.2〜0.4mm 小さく仕上がる。実物のネジとモーターを当てて、本番の穴径パラメータを決める。

### 形状

- 板：70 × 45 × 3mm。原点は板の左下角、上面に刻印する。

| 位置（板の左下が原点） | 形状 | 目的 |
|---|---|---|
| (6,38) (14,38) (22,38) | Ø1.6 / Ø1.8 / Ø2.0 の貫通穴 | M1.4 ネジの逃げ穴 → `motor_screw_clear_d` を決める |
| (34,38) (42,38) (50,38) | Ø2.2 / Ø2.4 / Ø2.6 の貫通穴 | M2 ネジの逃げ穴 → `m2_clear_d` を決める |
| 各穴の真下 Y=31 | 数値の刻印（「1.6」など）。文字高 3mm、深さ 0.4mm、太めのフォント | どの穴か分かるように |
| 中心 (14,14) | モーター取付パターン：一辺 6.5mm の正方形の角に Ø1.8 × 4、中心に Ø4.5 | 実物のモーターを当てて、穴位置と「一辺か対角か」を確認 |
| 中心 (48,15) | ESC 取付パターン：20×20mm の正方形の角に Ø2.4 × 4 | 実物の ESC を当てて確認 |
| (64,38) | 高さ 4mm・Ø3.6 のボス、中心に Ø1.8 の下穴 | M2 ネジを PETG に直接ねじ込めるか → `m2_tap_d` を決める |
| (64,15) を中心に Y 方向 | 幅 2.0 × 長さ 12mm のスリット | Pico のピンヘッダが通るか確認 |

### 印刷

- 平置き、PETG、壁 3 周、インフィル 30%。約 10 分。

### 確認と反映

1. 各穴に実物のネジを入れて、「スッと通るがガタつかない」穴径を選び、パラメータに書き戻す。
2. モーターを当てて 4 穴が合うか見る。合わなければ、斜めの穴の中心間を測る。
   - 約 9.2mm → 一辺 6.5mm で正しい。
   - 約 6.5mm → 対角だったので、`motor_hole_pitch` を 4.6（= 6.5/√2）にする。
3. ESC を当てて 4 穴が合うか見る。
4. ボスに M2 ネジをねじ込み、割れずに締まるか見る。割れたら `m2_tap_d` を 0.2 上げる。

## 6. パーツ 2：下板（アーム一体）

厚さ `plate_t`。下面を Z=0 とする。

### 6.1 本体

- `body_w × body_l` の長方形を原点中心に置き、角 R `body_r`。X -24〜+24、Y -40〜+40。

### 6.2 アーム ×4

- 原点からモーター中心 (±motor_offset, ±motor_offset) へ 45° 方向に伸ばす。幅 `arm_w`、厚さ `plate_t`。
- 上面の中央にリブ（幅 `rib_w`、高さ `rib_h`）を付ける。
  - 範囲は本体の縁からモーターパッドの縁の 3mm 手前まで。
  - 脚の取付位置（中心から `foot_r`）の前後 4mm は、ネジ頭が座るようにリブを切る。
- 結束バンドは腕に巻いて使うので、穴は開けない。

### 6.3 モーターパッド ×4

- モーター中心に Ø `motor_pad_d`、厚さ `plate_t` の円。
- 取付穴：一辺 `motor_hole_pitch` の正方形の 4 隅に Ø `motor_screw_clear_d`。正方形の辺は X・Y 軸に平行。
- 中心穴：Ø `motor_center_hole_d`。
- パッドの縁の、機体中心側に 3×2mm の切り欠きを付ける（モーター線を通すため）。

### 6.4 穴とスリット

| 用途 | 位置 | 形状 |
|---|---|---|
| ESC 取付 | (±10, -6)、(±10, -26) | Ø `m2_clear_d` 貫通。**下面側に座ぐり** Ø `m2_cbore_d` × 深さ `m2_cbore_depth`（ネジ頭がバッテリーに当たらないように） |
| 上段支柱 | (±20, ±20) | Ø `m2_clear_d` 貫通 |
| ストラップ（前） | X ±11、Y 中心 +10 | `strap_slot_w` × `strap_slot_l` の長穴（Y 方向に長い） |
| ストラップ（後ろ） | X ±11、Y 中心 -16 | 同上。ESC の下を通る |
| 脚 | 各アームの中心線上、原点から `foot_r` の位置 = (±28.28, ±28.28) | Ø `m2_clear_d` 貫通 |
| バッテリー線の出口 | 後端中央（Y = -40） | 幅 10 × 奥行 4mm の切り欠き |

### 6.5 印刷

- 下面をベッドにして、サポートなし。
- 外形はおよそ 119 × 119mm で、SV06 に収まる。

## 7. パーツ 3：上段デッキ

厚さ `deck_t`。組立て時は下面が Z = 20（下板の上面の高さ ＝ `plate_t`）＋ `stack_h` の位置に来る。

| 形状 | 位置・寸法 |
|---|---|
| 外形 | `deck_w × deck_l` を原点中心に置き、四隅を `deck_chamfer` で面取り |
| 支柱穴 | (±20, ±20) に Ø `m2_clear_d` 貫通 |
| Pico 用ボス ×4 | (±`pico_hole_x`, ±`pico_hole_y`) に Ø `pico_boss_d` × 高さ `pico_boss_h`。中心に Ø `m2_tap_d` の貫通下穴 |
| ピンヘッダ用スリット ×2 | X = ±`pin_row_x` を中心に、幅 `pin_slot_w` × 長さ `pin_slot_l`（Y 方向） |
| 軽量化穴（任意） | スリットの外側の帯（X ±11〜±17、Y ±14 以内）に限る |

- ボスの縁（X 7.5）とスリットの内縁（X 7.89）の間は約 0.4mm しかない。ボスとスリットをつなげてしまってよい（ピンが通る X 8.57〜9.21 を塞がなければ問題ない）。
- **Pico の向き**：USB 端を後ろ（Y-）、アンテナ端を前（Y+）。
- **印刷**：ボスを上にして平置き、サポートなし。

## 8. パーツ 4：脚 ×4

- Ø `foot_d` × 高さ `foot_h` の円柱。
- 上面（アームに当たる面）の中央に、M2 ナット用の六角穴（対辺 4.1 × 深さ 1.8）と、Ø `m2_clear_d` の貫通穴。
- 取付：アームの上から M2×8 のネジを通し、脚の六角穴のナットで締める。
- 印刷：上面を上にして、TPU（95A）で速度 20mm/s 程度。TPU がなければ PETG で刷り、底にゴム足を貼る。

## 10. 守るべき条件（理由付き）

1. **プロペラとの干渉**
   - 上面から見て、各モーター中心から半径 36.75mm（= 2.5inch 半径 31.75 ＋ 5）の円の内側に、プロペラ面より高い部品（支柱、上段デッキ、Pico）を入れない。
   - 理由：プロペラが当たるため。今は Ø52.2 を使うが、2.5inch に替えても作り直さずに済むようにしている。
   - 下板とアームはプロペラ面より低いので、円の内側に入ってよい。
   - 計算上、デッキの面取り部とモーター中心の最短距離は約 37.9mm（余裕 1.1mm）。面取りを小さくするとこの条件を破る。
2. **モーターのネジ長**
   - 「板厚 3mm ＋ 1.5mm 程度」まで。M1.4 なら ×4mm 前後。
   - 理由：長いネジはモーター内部のコイルに当たり、ショートしてモーターや ESC が焼ける。モーターのネジ穴の深さは、ノギスのデプスバーで測る。
3. **アンテナ**
   - 上段デッキの前半の上下に、金属部品を置かない。
   - 理由：Pico 2W の Wi-Fi/BLE で操縦する予定のため。PETG で覆うのは問題ない。
   - 将来カーボンで作るときは、アンテナ下を 12×10mm くり抜く。
4. **ストラップの隙間**
   - ESC の下（下板の上面から ESC の下面まで）に、ストラップが通る 3mm 以上の隙間を残す。
   - 理由：バッテリーを留めるベルクロが、下板の上面を横切って通るため。
5. **IMU の位置**
   - IMU は ESC から 5mm 以上離し、スリットの上に置かない。
   - 理由：ESC の熱と、ストラップの締め付けによる歪みを避けるため。

## 11. 作図後に確認すること

- [ ] 条件 1：支柱・デッキ・Pico ダミーと 2.5inch 上限円筒の干渉（Fusion の「検査 → 干渉」）がないか。最短距離も記録する。
- [ ] 前のスリット（Y +4〜+16）と IMU（Y +18.8〜+35.2）が重ならないか。
- [ ] 後ろのスリット（Y -22〜-10）と、ESC 穴の座ぐり（Y -8.1〜-3.9、-28.1〜-23.9）が重ならないか。
- [ ] ESC ダミーと後ろ側の支柱（X ±20）の隙間が 3mm 以上あるか。
- [ ] 下板の外形寸法が 220×220mm に収まるか。
- [ ] 各パーツの体積から推定重量を出す（PETG 密度 1.27 g/cm³。Fusion の「検査 → プロパティ」で体積が見られる。実際はインフィル 30% なので、ソリッド重量の 6〜7 割が目安）。
- [ ] 目安：下板 約 16g、デッキ 約 7g、脚 4 つで約 4g、合計 25〜35g。

## 12. SV06 での印刷設定（PETG）

| 項目 | 値 | 理由 |
|---|---|---|
| ノズル温度 | 240℃前後 | |
| ベッド温度 | 80℃ | |
| 冷却ファン | 30〜50% | 強すぎると層どうしが付かず、アームが折れやすい |
| 層厚 | 0.2mm | |
| 壁 | 4 周 | アームは曲げの力を受けるので、外壁を厚くした方が強い |
| インフィル | 30%（ジャイロイドなど） | |
| ベッド面 | 付属の粒面 PEI ならそのまま。平滑 PEI ならスティックのりを薄く塗る | PETG が強く付きすぎて剥がすときに板を傷めるため |
| フィラメント保管 | 乾燥剤と一緒にチャック袋へ | 湿気を吸うと糸を引く |
