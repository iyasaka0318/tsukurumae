# OrcaSlicer：SV06 / PLA 印刷設定プリセット v1

PCにあるOrcaSlicerのSV06プリセットを確認して作成した、読み込み用のプロセスJSONです。
元のアプリ設定ファイルは変更していません。0.4mmノズル用。SV06通常版／High-Speedのプリンター設定に対応させています。

## 読み込み

1. OrcaSlicerで使用中のSV06 0.4mmプリンターとPLAを選ぶ。
2. 「File（ファイル）→ Import（インポート）→ Preset Configs／Import Configs」に相当する設定読み込みから、JSONを選ぶ。2つをまとめたZIPも同封。
3. 「Process／プロセス」の選択欄で `SV06_PLA_Fit_NoBrim_v1` または `SV06_PLA_Parts_OuterBrim_v1` を選ぶ。

JSONはモデル用の「開く」やSTEP/STL用の読み込みではなく、設定用の読み込みで扱う。
親設定 `0.20mm Standard @Sovol SV06` が必要。現在のPCには存在することを確認済み。
別PCで見つからない場合はSovol SV06のシステムプリセットを有効にする。

## 使い分け

| プリセット | 用途 | ブリム |
|---|---|---|
| SV06_PLA_Fit_NoBrim_v1 | 広い底面の穴・寸法確認ゲージ | なし |
| SV06_PLA_Parts_OuterBrim_v1 | 底面が狭い部品など、外側の接着補助が必要な試作 | 外側のみ5mm、部品との隙間0.15mm |

共通：層厚0.2mm、初層0.2mm、壁4周、上下面5層、インフィル30% Gyroid、サポートなし、ラフトなし。
初層20mm/s、外壁25mm/s、内壁40mm/s。SV06標準プロセスを継承し、High-Speedプロセスの外壁100・内壁150mm/sは引き継がない。
穴・外形のXY補正は0。寸法試験の結果を補正値で変えない開始設定。

**温度・流量・冷却は選択中のPLA設定、プリンターの開始／終了G-codeは選択中のプリンター設定を使用する。**
両プロセスは試作開始値で、あらゆる形状の接着・強度・嵌合を保証するものではない。
底面の線間に隙間があれば、設定ファイルだけで直ったと扱わず初層の状態を確認する。

## 向き・倍率は別

JSONのプロセス設定は、モデルの向き・位置・倍率を固定しない。ゲージは平らな面を下、ボスを上、倍率100%で配置する。
個別オブジェクト／プレートの設定や、モデルの可変層高・ペイントサポートに上書きされていないかプレビューで確認する。
モデルの向きまで含めて再利用するときは、配置後にOrcaSlicerのプロジェクトとして `.3mf` を保存する。
