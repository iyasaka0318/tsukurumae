## v5の変更

**電源を制御系とモーター系に分離した**（2026-10-03、ユーザー判断）。電池→ヒューズ→MASTER_SW予約位置（現状は短絡線）→BAT_Lから、固定5Vの制御系と、モーター電源スイッチ→左右6Vのモーター系へ分岐する。非常停止はモーター電源スイッチで行い、Picoは電池給電で動作を続けるので、RAMログは試行中のUSB接続なしで残る。

これに伴い、v4のUSB常時接続、上側ケーブル曲げ、背面固定点C1、車軸上240mmの高さ予約を廃止した。USBはログ回収・書込み時の挿抜空間だけを残す。試行中のケーブル外力が交絡要因から外れる。完全OFFは当面XT30を抜いて行い、MASTER_SWへ入れるスイッチは研究室の在庫を見て判断する。v4は変更せず保存している。

主基板の部品・四隅固定予約はv3を維持する。[主基板を含むv3配置図](倒立ロボット_配置計画_v3.png)と、v5の電源系統・側面図を併用する。

## この版で固定する設計

研究の本編に微小遅延と**1/2/3/5/8周期の指令遅延線**を含める。Core0区間はCYCCNTを主計測、DRDYからの全応答は外部GPIOで補う。L0固定反映は対策候補へ追加する。watchdog後のRAMログ回収をNOLOAD領域・scratch・再起動状態まで具体化した。これらは実装仕様であり、動作確認済みではない。

電源は固定5V＋左右6Vを維持。**標準構成Aは左右吸収回路を装着して評価を通す計画**で、回路方式・部品はまだ検証前の候補。未装着・未評価では駆動を許可しない。電源試験で省略を認めた構成Bのみ、設定・電池位置・重心モデルを切り替える。A/Bを同一機械条件としてCore1負荷比較に混ぜない。

主基板の四隅12×12mmを最初に予約し、部品配置を変更した。既存の穴座標は未測定なので、新たな穴を今の候補座標に合わせて開ける指示ではない。前後バンパーを予約し、開始時の傾角停止を±8°へ変更した。

部品は2026-10-03に全品注文済み。基本3,530円＋回生評価用850円＋0.1µF積層セラミック1パック100円＝4,480円（モーター・送料・測定器別）。PIO分周・ADC応答・ARM上限も修正した。

## 研究面の点検

研究資料は新規性を強く断定しているが、こちらの確認は「実験として成立し得る」であり、世界初・受賞を保証しない。RP2350でのマルチコア推論等の先行例はあるため、差分はRTOSの応答時間と物理性能の同時計測、干渉条件、対策の比較に絞って説明する。

| 項目 | 計画と指摘 |
|---|---|
| MCU | Pico 2 WHのRP2350。比較中はクロック、コンパイラ、RTOS設定を固定。全条件でCYW43未初期化、オンボードLEDも使わない |
| RTOS | FMP3のPico 2用公開ポートを出発点とし、Core0制御の配置を固定。OS自作・複数RTOS比較まで同時に広げない |
| 基準制御 | Core1アイドルで安定倒立を先に確立。無負荷でも不安定ならコア干渉の評価へ進まない |
| 負荷条件 | アイドル、CPU計算、SRAMアクセス、XIP実行/アクセス、TinyML。アクセス量・実行時間・配置を記録 |
| 推論 | 最初は判定結果を制御へ反映しない。制御則まで変えると時間的干渉との切り分けが困難 |
| 制御周期 | IMU ODRと合わせた1kHzを開始候補、500Hzも検討。実機の安定性とWCETから決め、意図的に短すぎる締切でミスを作らない |
| 時間の定義 | DRDY→制御開始、制御開始→PWM更新、DRDY→PWM更新を区別。ISR入口からの時間だけを応答時間と呼ばない |
| 計測 | Core0区間はCYCCNTを主、DRDY全応答は外部GPIO、共通タイマーはコア間・長時間用。GPIO書き込みにもバスアクセスがありゼロ負荷ではない。空測定と同じ計測コードの基準条件を含める |
| 時計 | 150MHzの32bit CYCCNTは約28.6秒で周回。差分の周回を処理する。別コアのCYCCNTを同期せず直接引き算しない |
| SRAM配置 | リンカmapと実アドレスでバンク配置を確認。通常のインターリーブ領域では変数をずらしただけで別バンク専有を証明できない |
| 物理指標 | 角度RMS、安定維持時間、転倒率、変位/速度、同条件の外乱応答。傾きの符号と単位を固定 |
| 交絡要因 | 電池電圧、ギヤ遊び、摩擦、床、タイヤ、重心、ケーブル外力、温度、電流制限の作動を記録・固定 |

「転倒＝デッドラインミス」は成立しない。電源低下やギヤ遊びでも転倒する。負荷あり/なしの順番を入れ替え、各条件を複数回測り、平均だけでなく最大値・分布・失敗回数と試験数を報告する。タイミングが変わっても倒立性能が変わらない結果、干渉が検出されない結果も研究結果として扱える。

### 制御・計測・ログの固定仕様

- エンコーダ：PIO0の2SMで4逓倍、**分周なし150MHz**。最悪10cycleのPIOループは約0.067µs。FIFOのCPU読出しや共有バス待ちは別に測り、無制限ブロックを避ける。速度比例のCPU割り込みは使わない。
- モーター：20kHz駆動／ブレーキ、ゼロ指令HH、異常LL。内部Mixed Decayの回生は評価する。
- 計測：ISR入口・制御開始・PWM書込みを同じCore0のCYCCNTで記録。ただし実DRDY→ISR受付の待ちを除くため、外部計測を併用する。DWTのsleep時挙動と計測自体の負荷も確認する。
- 遅延：0～400µsに加え、毎周期計算を続けるk=0/1/2/3/5/8遅延線を本編に入れる。k周期は正確に設定するが、実時間は周期誤差・PWM待ちを含め実測する。安全停止は遅延させない。
- 対策：L0固定反映を追加し、平均遅延とジッタ低減の両方を評価する。L0未達を1ms制御締切超過と混同しない。
- ログ：64,000byte物理ログ＋65,536byte直前タイミングリング＋512byteヘッダー。専用NOLOAD、scratch0～3、再起動時の回収状態。scratch4～7を使わず、特殊起動のscratch2/3用途とも混在させない。給電継続中のwatchdogが対象で、電源断を含む永続ログではない。

手順・交絡の扱い・ログ途中書込み・実装後の故障注入試験は [計測とログ実装仕様v5](倒立ロボット_計測とログ実装仕様_v5.md) にまとめた。400µsで差がなくても校正を終えず周期遅延へ進む。安全停止・転倒・電源異常はそれぞれ記録する。RAM予算130,048byteが実際の推論arena・RTOS・スタックと共存できることをmapで確認する。比較中のログ配置・ログ処理量を固定し、試験中にFlashへ書かない。

IMU値は制御にも評価にも使うため、完全に独立した真値ではない。代表試験をスマホの側面動画・目印と比較し、角度推定が大きく破綻していないか確認する。高価な別センサを今追加する必要はない。ロジックアナライザは後で学校予算、電源試験のオシロスコープと電流制限電源は研究室で借用を想定する。

## 接地角とエンコーダ保護

後端点(X=-a,Z=z)が後傾βで床に触れる条件は `r + z*cosβ − a*sinβ = 0`。r=32.5、a=60、z=-11～-15なら**21.8～17.7°**。これはレビューの仮下面位置の計算で、実物の接地角ではない。v2の±25°では先に後端が触れ得る。

後バンパーをX=-75、下面Z=-18へ置く開始案では、同じrで約11.4°、荷重時の有効半径31mmの例では約10.2°でバンパーが先に接地する。後端より後ろ・下にあることで、0～90°の後傾では仮定したエンコーダ下端より先に地面を受ける。前側もX=+75に同じガードを置き、荷重はフレームへ逃がす。センサ基板をバンパーの支持点にしない。

開始時のソフト停止は**±8°**。実機では左右モーター・エンコーダ・端子・吸収抵抗を含む包絡形状を測り、荷重時／タイヤ圧縮時に最初に触れる点を確認する。ガード変形も含めた実接地角θminに対し `θstop≤min(10°,θmin−2°)` として更新する。LL停止で落下が止まる保証はなく、物理ガードが必要。試行中に接地したら外部動画・目印で検出し、その後を通常の無接触倒立と混ぜない。

寸法CSVと計算値は [接地角の計算](接地角_v3_計算.csv)。強度・転倒時のガード変形は未検証。印刷CADでは「実エンコーダ後端より10mm以上後ろ、下面より3mm以上下」を確認し、仮X=-75をそのまま実物適合と扱わない。

## USBの挿抜空間（ログ回収・書込み時のみ）

v5では**試行中にUSBを接続しない**。モーター電源スイッチで止めてもPicoは電池給電で動き続けるので、試行後に機体を静置してからUSBを挿し、RAMログを回収する。USBを挿したまま行うデバッグ試行は別条件として記録し、比較データへ混ぜない。

| 予約 | X範囲mm | Y範囲mm | Z範囲mm | 用途 |
|---|---:|---:|---:|---|
| USBプラグ・着脱経路 | 12～35 | −28～+3 | 154～210 | v4と同じ。推定X18～26、上向きプラグ約30mmと指の逃げを含む |

この領域に固定ガード・横桟・電池台・ストラップ・スイッチを置かない。ケーブルの曲げ・固定点の予約は不要になった。挿抜時はPicoとソケットを指で支え、基板をこじらない。座標の前提（`Y=u−40`、USB中心Y≈−12.5）と、ソケット・Pico・プラグの外形が未測定である点はv4と同じ。

構成Aの電池台予約X=−57～−33、Y=±40、Z=107～133は維持する。構成Bの電池中心X52/Z175（台X40～64・Y±40・Z162～188）も、USB挿抜空間の前端X35との隙間5mmを保つため維持する。挿抜空間と電池台・主基板・吸収部品予約の非重複は計算確認した（[計算確認のJSON](配置計画_v5_計算確認.json)）。

### CADを確定する前の実物確認

1. Pico＋ソケットの装着状態でUSB中心のX/Y/Zと、プラグ・成形根元の外形・着脱ストロークを測る。
2. 予約を型紙／仮受けで再現し、A/Bの電池台・ストラップ・上側面のスイッチ類がUSBの挿抜を妨げないことを確認する。
3. 電池を接続しモーター電源スイッチOFFの状態で、USBを後から挿してもPicoがリセットされず、ログを回収できることを実機確認する。

吸収回路を外して電池を動かさなければ本体重心は約−7mm。旧調整前端X=+10でも約−1.92mmで残る。v3のB電池中心X31/Z175はUSBプラグと重なるため使わない。v4以降はUSBの前側X52/Z175へ移し、仮本体X重心は**+1.97mm**となる。Z重心60.21mmから静的な鉛直姿勢の偏りを単純換算すると約1.88°だが、許容性や実際の制御目標角を保証する値ではない。Bは部品到着後の実重心・慣性の再同定が必要で、重心ゼロの確定構成ではない。

Bの上部支柱・電池台、MASTER_SW（追加する場合）の質量はこの比較表へまだ加算していない。v4で予定したC1支持部は廃止。実CADでは質量・強度・USB挿抜空間を更新して再計算する。重心の補正が必要でも、USB挿抜空間を侵す位置へ電池を戻さない。

研究モデルは車輪質量・慣性を本体と分ける。A/Bで重心・慣性・高さが変わるので、同じ制御パラメータで機体構成の差をCore1干渉の差と扱わない。採用する1構成を固定し、実質量・吊り下げ等の実重心で再同定する。回転するモーター／ギヤの等価慣性も点質量だけで済むとは限らない。

6V無負荷160rpm、半径32.5mmから上限速度目安0.545m/s。定格トルク0.2kgf·cm×2から力の目安1.21N、400gなら3.0m/s²。これは定格トルクでの静的計算であり、無負荷最高速度で同時に得られる力ではなく、1A制限時のトルクも保証していない。摩擦・ギヤ遊び・効率・車体慣性を含む実機で、小さい傾きから試す。大きく倒れた姿勢からの起き上がりは今回の必須性能にしない。

## 安価な変更候補と残る現物確認

5V固定電源は標準採用。吸収回路の標準装着計画Aと、省略承認後の構成Bを区別する。850円を買えば電源問題が解決するという意味ではない。張り付き検出、電圧閾値、操作者によるモーター電源遮断と温度評価を全体回路案v5に記載した。

今の購入候補で主要機能は揃うが、最後まで不明のままにできないのは車輪軸の嵌合/抜け止め、モーター端子順、電源・回生波形、全質量、マウントねじ長。部品到着後の確認項目として残す。3Dプリントの電池ホルダー・モーター受け・基板受けは購入しない。ストラップ/結束バンドが手元になければ必要。ヒューズの電気接点は印刷物で代用しない。

テスター、はんだ付け道具、秤、ノギスも組立・評価に必要。ロジックアナライザは機体完成後でもよいが、回生波形は初回倒立前に確認する。測定器は今回の秋月機体部品合計へ含めない。
