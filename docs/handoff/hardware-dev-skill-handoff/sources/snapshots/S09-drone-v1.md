# 趣味用ドローン：Pico W・MPU-6050・共用バッテリー v1

2026-10-05。Pico W（ヘッダ実装済み）と手持ちGY-521を使う機械設計の初版。ユーザー確認により、倒立ロボットと共用するのはバッテリーだけ。原本の旧仕様・倒立ロボットv5は変更していない。CAD形状は検証したが、実機適合・強度・飛行性能は未検証。

## 今回の構成

| 項目 | 設計 |
|---|---|
| MCU | 第1世代Pico W / RP2040、ヘッダ付き。IC 20953-PICOWは公式認証資料のPico Wと一致。出荷時のW/WH区別はヘッダ追加の有無だけで決めない |
| センサ | 手持ちGY-521 / MPU-6050、外形21.2×16.4mm。IMUの向き・軸は実装時にソフトへ反映 |
| モーター | 旧ドローンのYSIDO 1104 7500KV×4を継続する仮組み。取付ピッチ6.5mmの正方形、確認済みの穴径2.4mm |
| ESC | 手持ちHAKRC 15A 4in1、穴配置20×20mm。グロメット内穴約2mm・上下を含む全高約6.2mmという過去報告を反映 |
| 電池 | GNB 2S 550mAh / 70×17×12mm、XT30。普段の満充電8.4Vを前提にする。電池本体の寸法は過去実測記録 |
| 降圧基板 | MINI360をドローン専用として1枚残す。ESC用の電力は降圧せず、電池から供給する案 |
| 機体 | True X、対角軸間145mm、下板・上段デッキ・下面の固定電池トレー・脚4本 |
| 材料 | 手持ちPLAで寸法・仮組み試作。飛行に使える強度の認定ではない |

## 旧案から変更した点

- 電池は固定トレーに載せ、幅10mmのベルクロ2本で保持する。XT30を抜いてベルクロを開くと、電池だけ取り出せる。充電は電池を外して既存のISDT充電器で行う。トレー・ESC・降圧基板・制御系を電池と一緒に外す必要はない。
- ストラップの穴を電池トレー側へ移した。ストラップがESCとIMUの下を横切る旧案を廃止。電池上面と下板の間は2mmを予約し、ストラップと緩衝材の実物で確認する。
- Picoはデッキから15mm浮かせる。コネクターが基板下面から12mm下がる仮定で、コネクター下端からデッキまで3mm残す。ピンヘッダ用の細いスリットと穴脇の薄肉ボスは使わない。
- Picoの穴は十分な面積のデッキへ開ける。Pico側の支えは別体の細径ナイロンスペーサーを使う。デッキの側端を開放し、配線を横へ出せるようにした。
- MINI360はデッキ下面の中央へ、絶縁した状態で結束バンド固定する。電池と共に取り外さず、出力調整部を不用意に押さえない。
- ESCをY=-21へ、IMUをY=+8.5へ移した。両者の外形間は5.3mm。アンテナ端の下へIMUを置く旧配置を避ける。
- PLA仮組み用にアーム幅を8→10mmにし、根元を補強した。上面リブは脚のねじ頭周囲で中断し、ねじ座面を確保する。
- 電池トレーの取付ねじ先端が地面へ当たらないよう、脚を25mmにした。

## ファイルの使い方

`Assembly_reference.step`はFusionで組立配置を見るためのファイル。`REF_`は購入部品・手持ち部品の簡略ダミー、`KEEP_`は予約空間であり、印刷しない。プロペラの円板も印刷しない。

印刷対象は以下の5種類。部品単体のSTEP/STLは、印刷用に下面をZ=0としてある。

| ファイル | 個数 | 向き |
|---|---:|---|
| BottomPlate.step / .stl | 1 | 広い平面を下、リブを上 |
| TopDeck.step / .stl | 1 | 平置き。細いボスはない |
| BatteryCradle.step / .stl | 1 | 平らな底を下、柱を上 |
| Foot.step / .stl | 4 | 円柱を立て、六角ナット穴を上 |
| ESC_Spacer.step / .stl | 4 | 円筒を立てる。市販M2スペーサーで代替可能 |

STEPにFusion固有のスケッチ履歴・ユーザーパラメータはない。寸法原本は`parameters.json`と、親フォルダの`build_drone_pico_w_v1.py`。既存CadQuery環境で再生成する。組立STEPをOrcaSlicerへ丸ごと読み込んで印刷しない。

## 電池を共用する電源構成

```text
共用GNB 2Sバッテリー
  └ XT30を差し替える（同時に2機へつながない）
       ├ 倒立ロボット側：既存v5の電源回路
       └ ドローン側：
           電池+ ─┬─ ESCのBAT+ → 4モーター
                  └─ 専用MINI360 IN+
                       OUT+ [4.8〜5.0Vを実測調整]
                         → ショットキーダイオード → Pico VSYS（39番）
                           ダイオードの帯側がPico側
           電池- ─── ESC GND・MINI360 GND・Pico GND
```

電池の8.4VをPicoへ直接入れない。Pico Wの電源入力は1.8〜5.5V。MINI360は制御系専用で、4モーターの電力を通さない。XT30を抜くことがドローンの全電源OFFになる。USBからPicoだけ給電する試験では、電池は抜いておく。

モーター系の大電流GNDをPico/IMUの細い配線へ流さず、ESCの電池端子付近で分岐する。倒立ロボットの6V降圧・回生吸収・5Aヒューズをドローンへ流用する構成ではない。ESCの個体の対応セル数、端子順、信号規格は使用前に本体資料で確認する。

GPIOの予約案（ソフトとESC仕様を確定するまで仮）：

| Pico | 接続先 |
|---|---|
| GP0 / GP1 | MPU-6050 SDA / SCL（I2C0） |
| GP2 | MPU-6050 INT |
| GP4〜GP7 | ESCの4入力。ESC端子の並びや回転順は仮定しない |
| 3V3(OUT) | I2Cプルアップの3.3V基準 |
| GND | IMU GND、ESC信号GND |

MPU-6050チップ自体の電源範囲は2.375〜3.46V。手持ちGY-521のVCC端子は基板レギュレータを経由する可能性があるので、チップの電圧範囲と混同しない。基板VCCを3.3V/5Vのどちらへ接続するかは、個体のレギュレータ・プルアップ先を確認して決める。SDA/SCL/INTがPico側の3.3V範囲に収まることを確認する。型番だけから5V接続を断定しない。

Wi-Fi/Bluetoothを操縦へ使う場合も、通信の途絶で推力指令を保持し続けない制御を用意する。今回の成果物は機械設計と接続予約であり、飛行用ファームウェアは含まない。倒立ロボットのRP2350用の計測仕様をRP2040へそのままコピーしない。

## CAD検証と残る確認

`validation.json`に各部品の有効な単一ソリッド、STEP再読込、閉じたSTL・面の向き、配置した部品と構造部の体積干渉を記録する。

生成環境の注記：既存CadQuery 2.8環境は、全ファイル出力・検証結果表示の後に終了コード1を返した（エラー詳細は表示されなかった）。出力した検証JSON・ZIP内のファイルは別途確認した。形状チェックの完了と、生成プロセスの正常終了は区別する。OrcaSlicerでの実スライスと実印刷はまだ行っていない。

- 電池・Pico・ESC・IMU・降圧基板・代表コネクター・USBプラグの各ダミーと構造部は体積干渉なし。
- 将来2.5inchプロペラの外周からさらに5mm広げた予約円筒に対し、上段の部品は干渉なし。最小隙間は約1.16mm。この値は実プロペラ先端に対して約6.16mmの平面余裕を持たせた設計に対応し、配線・振動・造形誤差は別に確認する。
- 外部金属を避けるアンテナ予約はX=±13、Y=17〜33、Z=0〜55。設計者が選んだ保守側の配置範囲であり、メーカー指定の寸法そのものではない。樹脂や電池などによる無線性能は距離だけでは保証できない。
- 重量はPLA密度1.24g/cm³でのCAD完全ソリッド相当を出力する。インフィル30%だから重量が30%になるとは扱わない。印刷重量はOrcaSlicer、実重量は秤で確認する。旧仕様の機体103〜113gを保証値として引き継がない。

優先して確認する実機寸法：

1. **モーターのねじ保持**：付属首下3.8mm、板厚3mmなので突き出しは0.8mm。安全なねじ込み深さ・十分な保持は未確認。付属ねじで固定できたと断定しない。モーター取付部厚2mmは許容挿入深さの保証ではなく、長いねじへ勝手に交換しない。実測後、局所座ぐりかねじ長のどちらを変えるか決める。
2. **Picoのスペーサーと端のコネクター**：15mm高さでコネクター下端に3mm残るのは、全突出12mmの予約仮定。実物のコネクター高さ・線の曲げ・端のピンでスペーサーに当たらないことを確認する。前回3.2mmスリットが緩いという結果を「全体を縮小」で解決しない。
3. **ESC**：簡略ダミーは全部品・はんだ盛り・側面コネクターまで保証しない。グロメットの支持面にØ4スペーサーが合うか、周辺パッドを押さないかを確認する。
4. **電池**：リードがどちらの端から出るかは記録上未確認。後ろへ向け、端子と根元の取り回しは電池を仮置きして確認する。ベルクロ・緩衝材を含めて電池を押し潰さず保持する。

## 印刷

OrcaSlicerで部品単体のSTEP/STLを読み込み、倍率100%。大きな平面部品は既存の`SV06_PLA_Fit_NoBrim_v1`を開始値に使える。脚や小スペーサーは接着状況に応じ`SV06_PLA_Parts_OuterBrim_v1`を使う。中央の開口・穴の中へブリムを入れない。各部品は基本的にサポート・ラフトなし。

既存の初層の隙間・糸引きは原因と調整値が確定していない。JSONを使っただけで解消済みとは扱わず、初層プレビューと実際の最初の層を確認する。文字は機能に不要との前回評価に従い省略した。

最初の印刷対象は電池トレーでよい。電池の載せ替えを仮組みで確認し、その後フレームとデッキを組む。飛行前にはモーター固定・配線固定・推力・振動・停止動作を実機で確認する。
