# Pico 2 WH取付・ジャンパ線接続テスト v2

印刷ファイル：Pico_2_WH_fit_gauge_v2.stl（mm）
Fusionで開くファイル：Pico_2_WH_fit_gauge_v2.step

外形34×60mm、板厚2.5mm、ボス高さ4mm、全高6.5mm。
取付穴位置11.4×47mmと穴径2.4mmは前回と同じ。
スリットは2.0mmから3.2mmへ拡幅し、長さ52mm・ピン列中心間17.78mmを維持。
円形ボスを直径4.8mmへ広げた後にスリット形状で外側を切り落とし、内側への支持面積を増やす。
文字を省略し、USB側の縁に幅5mm・深さ1mmの切り欠きを入れた。

## 印刷

PLA、0.4mmノズル、層厚0.2mm、壁4周、上下面各5層、インフィル30%。
ボスを上にして平置き。サポート・ラフトなし。倍率100%。
ブリムを使う場合、スリット内に付けない。
材質温度等は現在使用しているPLAの設定を使う。

## 確認

1. 切り欠き側にUSB端を合わせ、Picoが4ボスに同時に載るか。
2. 4取付穴が合うか。
3. 下面からメスジャンパ線の黒いハウジングを通して、ピンへ十分に挿せるか。
4. ボス付近の端のピンでも、黒いハウジングが引っ掛からないか。
5. 基板を浮かせたり傾けたりせず、ジャンパ線を抜き差しできるか。

取付穴は位置確認用の逃げ穴なので、PLAへ直接ねじ込む穴ではない。
ボスとスリットの間の最小肉厚は0.39mm。内側の支持面を広げているが、今回はコネクター適合確認用であり、本番の強度保証ではない。無理に締め込まない。
代表外形2.54mmのハウジングでは設計上片側0.33mmの余裕があり、CADでボス・板との体積干渉がないことを確認。現物の造形誤差とジャンパ線寸法は印刷後に確認する。

STEPはソリッド形式で、Fusion固有の作成履歴は含まない。生成原本はbuild_pico_test_v2.py（CadQuery用）。

## 印刷後の結果（2026-10-02のチャット報告、2026-10-03追記）

幅3.2mmのスリットに黒いジャンパ線コネクターは通ったが、コネクターとスリットの隙間は「ちょっと緩い」との評価。取付ねじが緩いという意味ではない。左の穴はつぶれかけたとの報告もある。

最終スリット幅と支持形状は未確定。最小肉厚0.39mmの部分を含め形状を再検討する。適正Zオフセット・流量等の校正値は得られておらず、この印刷メモを合格済みプロファイルとして扱わない。詳細は「テスト手順と設計更新.md」の印刷後フィードバックを参照。
