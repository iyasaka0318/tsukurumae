## 追加実測の反映

1. モーター付属ねじは頭径約3.5、ねじ外径約2、首下約3.8。M1.4想定を撤回しM2相当とする。ピッチは未実測なので、購入するM2ナットとの軽い手締めで互換性を確認する。無理にねじ込まない。
2. 取付部厚2mmは、コイルに接触せず挿入できる深さの保証ではない。付属ねじを板厚3mmに通すと突き出し約0.8mm。長いねじへの交換は本番モーターパッドの有効厚と許容挿入深さが決まってから。
3. 対角6.5mmなら穴中心半径3.25。中心穴半径2.25＋M2逃げ穴半径1.2＝3.45なので、穴同士が0.20mm重なる。元案の中心穴Ø4.5をそのまま採用できない。
4. ESCグロメットは上4、下1、全高約6.2、内穴約2。グロメットがあるので追加購入不要。全高6.2から逆算した基板厚約1.2は、実装部品の最大高さではない。ESCの部品を含む占有高さは別に保持する。
5. グロメット下面を長さ5mmのスペーサーで支えれば、基板下面は下板上面から約6mm。はんだ・部品・ストラップの厚さを引いた実際の隙間を確認する。ゴムを潰すまで締めない。
6. Pico 2 WHはヘッダ実装済みとして扱う。公式資料の基板外形21×51、取付穴Ø2.1、穴配置11.4×47、ピン列間17.78、ピンピッチ2.54を使用。元仕様のボス高さ4mmとスリット幅2mmは適合を保証する値ではなく、今回の試験条件とする。ヘッダ先端が通っても、メスコネクターを十分に差し込めるとは限らない。
7. Picoの板厚は公式データシート本文と図面等に表記差があるため、本番ねじ長の確定には現物の組立状態を優先する。今回の取付位置ゲージは板厚に依存しない。

## 印刷

PETG、0.4mmノズル、層厚0.2mm、壁4周、インフィル30%。本番と同じ上下層数・流量・XY補正を使う。広い平面をベッド側、文字とボスを上向き、サポートなし。STL単位はmmとして扱い、寸法を確認して100%で印刷する。

座ぐりは下面にあるため、実際の初層・ブリッジの影響も含む試験になる。深さ1.5mmは層厚0.2mmの整数倍ではなく、スライサーの丸めも評価対象。印刷時間・材料重量はスライサーで確認する。「10分」「ソリッド重量の6〜7割」は保証しない。

## M2_test_couponの見方

板左下をX=0,Y=0、文字側を上とする。刻印寸法はmm、深さ0.4mm。

| 場所 | 内容 | 判定 |
|---|---|---|
| 上の列 Y62、左から | 貫通穴Ø2.1 / 2.2 / 2.3 / 2.4 / 2.5 / 2.6 | 実物ねじが回さず通る最小径。付属ねじと購入ねじの両方を試す |
| ボス列 Y46、左から | 外径3.6・高さ4、下穴Ø1.6 / 1.7 / 1.8 / 1.9 / 2.0 | M2×6を上から試す。割れ・空回り・白化がなく保持できる径。これは切削タップの試験ではなく直接ねじ込み試験 |
| Y30の4穴、左から | 貫通Ø2.4、下面座ぐりØ4.2、深さ1.2 / 1.4 / 1.5 / 1.6 | 下からねじ頭を入れ、下面より飛び出さない深さと残厚を比較。刻印は深さ |
| 左下 SIDE 6.5 | 一辺6.5の4穴Ø2.4、中心Ø4.5 | モーターの4穴が同時に一致するか目視・軽い仮当て |
| 下中央 DIAG 6.5 | 対角6.5＝一辺4.596の4穴Ø2.4、中心Ø3.0 | 穴位置のみのゲージ。中心穴を縮めて独立穴を維持した。本番モーターパッドではない |
| 右下 ESC 20×20 | 穴間20×20、4穴Ø2.4 | グロメット内穴と同時に合うか。4本を無理なく通す。ゴム自体をこの穴にはめ込む試験ではない |

モーター側は電源を外し、付属ねじで無理なく位置を照合する。DIAG側で軸・クリップが中心穴に当たったら押し付けず、穴位置を目視で比較する。緩いゲージ穴だけでピッチの精密測定はできないが、一辺6.5と対角6.5の区別に使用できる。テスト板を飛行用部品として使わない。

下穴がすべて割れる場合は、穴径だけを拡大し続けず、ボス形状またはナット固定へ変更する。ボスを太くするとPicoのスリットやヘッダに干渉するため、本番で単純に拡径しない。

## Pico_2_WH_fit_gaugeの使い方

USB刻印側にUSB端、ANT刻印側にアンテナ端を合わせる。電源を外したPicoを、ピンを曲げずに上から載せる。

- 2列×全長52mmのスリットで、全ピンが通るか確認。
- 4本の高さ4mmボスに基板が同時に載り、がたつかないか確認。
- 4穴は位置確認用のØ2.4逃げ穴。ここへ直接ねじ込む設計ではない。必要ならM2×8と下面ナットで仮止めするが、まず置くだけでよい。
- 実際に使用するメスコネクターが下面から十分に差し込めるか確認。樹脂ハウジングとプレートが当たる場合、スリット幅・ボス高さ・開口形状を本番で変更する。
- USBケーブルとデバッグコネクターを挿せるか確認。
- このゲージは元案の0.39mmのボス〜スリット間隔を再現する。そこが欠けたり変形したりしないか確認する。
- アンテナ性能試験用ではない。本番ではアンテナ周辺の空間とIMUの配置を別途修正する。

## 2026-09-17 PLA実測結果

- モーター取付パターン：`SIDE 6.5` が一致。`motor_hole_pitch = 6.5 mm`（正方形の一辺）で確定。
- ESC取付パターン：20×20mmが一致。`esc_pitch = 20 mm`で確定。
- M2直接ねじ込み：造形穴2.0mmはきつめだが、ドライバーで締め込める。PLA試作では`m2_tap_d = 2.0 mm`を採用する。PETGでは再試験する。
- M2穴2.1mm：ユーザー報告は「手締めでも入るが、刺さる部分が短いと怪しい」。ねじ込まずに自由に通る逃げ穴として確認済みとは扱わない。本番候補のモーター穴2.2mm、支柱・ESCなどの2.4mmは用途別の設計値であり、下記の追加確認と区別する。
- Pico 2 WH：基板外形と4取付穴は一致。幅2.0mmの長穴には、ピンへ挿す黒い2.54mm系コネクターハウジングが通らない。`pin_slot_w = 2.0 mm`は不採用。ハウジング実測後に開口幅と位置を決定する。
- 文字：今回の設定では判読困難。本番部品に識別文字を設ける場合は、凹文字を大きくするか省略する。機能寸法には影響しない。
- 下面：初層の線が十分につぶれず、線間に隙間が見える。設計形状よりZオフセット／初層条件の影響が大きい。次回はZオフセットを0.02〜0.05mmずつノズル側へ下げ、隣接線が接する位置に合わせる。
- 糸引き：機能確認には支障なし。本番印刷前にPLAの乾燥、ノズル温度、SV06ダイレクトドライブのリトラクションを調整する。

## 2026-10-02 Pico接続部の追加確認

- ユーザーの写真・現物確認により、Picoの4取付穴位置が一致した。穴位置11.4×47mmを採用する。
- 基板下面のオスヘッダへ、下面側から1極メスジャンパ線コネクターを差す構成。板のスリットを通す必要があるのは金属ピンだけでなくメスコネクターの黒いハウジング。
- 現物ハウジング幅は2mm強。印刷済み2mmスリットには入らない。代表例のPololu 1極2.54mm系ハウジングでは外幅2.54mmだが、現物のメーカー・品番が同一とは確認していない。
- 次の設計案はスリット幅3.2mm・長さ52mm、ピン列中心X=±8.89を維持する。3.2mmは代表外形に造形・挿入余裕を加えた試作値であり、現物適合済みではない。
- スリットの内縁はX=±7.29となり、元の円形ボス外縁X=±7.5と平面上で0.21mm重なる。単純なスリット拡幅だけではなく、穴位置を保持したままボスの形状・支持部を見直す。コネクターの抜き差し・配線曲げの空間も確保する。
- モーターの一致を確認したSIDEゲージの4取付穴はØ2.4mmだった。以前の本番候補Ø2.2mmは未検証の推奨値なので、「現物適合済み」と扱わない。現時点で確認済みの穴径を使う場合はØ2.4mm。

## 2026-10-02 IMU変更候補

ユーザーがGY-521（MPU-6050）からStrawberry Linux #42688（ICM-42688-P）への変更を検討中。

- 販売元仕様：基板約12.8×10.2mm、基板と実装部品を含む厚さ2.6mm、端子を除く重量0.44g。旧GY-521の21.2×16.4mmの占有形状を、新モジュールの形状へ変更する候補として記録する。
- 端子はユーザーがはんだ付けする。端子・コネクター・配線曲げの高さは2.6mmに含まれない。固定ホルダーと配線方法を決めるまで、総高さは未確定。
- Picoの3.3V系に接続可能。単一電源使用時はVDDとVDDIOの両方へ3.3Vを供給する。I2CではCSをVDDIOへ、AD0をGNDまたはVDDIOへ接続し、外部プルアップが必要。SPI接続にも対応。
- CADでは外形縮小を活かして、機体中央に寄せた固定場所を検討する。端子を含む占有体積、ESCとの距離、Picoアンテナ周辺の空間を再確認する。取付ねじ穴の存在・位置を仮定して作図しない。
- MPU-6050とはレジスタ・初期化方法が異なるため、制御ソフトのセンサードライバーも変更が必要。
- 検討段階のため、この候補記録だけで本番CADの部品・配線を確定しない。

## 2026-10-02 Pico v2印刷後のフィードバック（2026-10-03追記）

この節は、保存済み設計記録に未反映だったユーザーのチャット報告と写真（IMG_20261002_160809.jpg）から追記したもの。新たな実測・印刷試験は行っていない。

- 幅3.2mmスリットでは黒いジャンパ線コネクターを通せたが、ユーザー評価は「ちょっと緩い」。後続の説明で、緩い対象は「黒いコネクターとスリットの隙間」と確認。ねじ穴やPico基板の固定が緩いという報告ではない。
- 「左の穴もつぶれかけてる」との報告がある。CAD検証記録では穴とスリットの間の最小肉厚が0.39mm。薄い部分の形状・支持を見直す必要があるが、写真だけでは変形原因を確定できない。
- 2.0mmスリットは通らず、3.2mmは通るが余裕が大きい。採用する最終幅は未確定。部品全体の縮小や一律XY補正で対処すると、一致していた4取付穴位置なども変わるため、スリットと周辺支持を個別に扱う。
- 判読困難な文字は、ユーザーから機能上重要でないとの評価。v2では省略済み。

### OrcaSlicerプリセットへの反映範囲

- 以前のPico v2印刷メモにある層厚0.2mm、壁4周、上下面各5層、インフィル30%は、今回のプロセスJSONでも維持している。ただしメモの推奨設定であり、印刷時の全設定を保存した実測済みプロファイルではない。
- 下面の線間の隙間と糸引きは記録済み。初層/Zオフセットを疑う記述は当時の推定で、原因の確定や調整後の合格報告ではない。適正Zオフセット・流量・温度・リトラクションの確定値は記録にないため、JSONへ推測値を入れない。
- スリットの緩さと穴脇の薄肉は形状側の検討事項。プロセスJSONを読み込むだけで改善済みとは扱わない。穴・外形のXY補正0は校正完了を意味しない。
- ドローンのモーター穴・ESC穴の一致は、その部品とテスト形状の結果。倒立ロボット用FIT0450の穴配置へ転用しない。
