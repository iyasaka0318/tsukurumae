# ドローン：配線実測と配置計画の更新待ち事項

2026-10-05。ユーザー指示により、現在は設計計画のみを整理する。既存のSTEP/STL・CAD生成ソース・配布ZIPは変更しない。

## 追加の現物情報

- ESCの6端子は表示が4・3・2・1・V・G。ユーザー測定でV–G電圧はバッテリー端子電圧と同じだった。Vを5V端子としてPicoへ直結しない。電圧一致だけで電流容量やBAT+との直結配線を確認したことにはならない。
- MPU-6050基板（手持ちGY-521）とMINI360には、基板上側からメスコネクターを差せる向きのピンヘッダが実装されている。写真でGY-521の8ピン列とMINI360の四隅4ピンを確認。MINI360の基板裏面からメスコネクター先端までの高さはユーザー実測20mm。GY-521の接続後の高さは写真から約20mm前後の概算。
- モーター単体試験もバッテリー給電で行い、USBによる書き込みと電池による駆動は別々に行う方針。まずESCの1チャンネルのみを使う。

## 次回CADへ反映する計画

1. **上向き接続空間を予約する。** 両基板について、基板・実装部品・上向きピン・差し込んだメスコネクター・配線の曲げを占有範囲に含める。MINI360はユーザー実測20mmに配線の曲げ空間を追加する。GY-521は写真概算約20mmを仮値として扱う。コネクターを上から抜き差しする作業空間も別に確保する。20mmをそのまま上下段間隔としない。
2. **MINI360の位置を再検討する。** v1のデッキ下面中央へ密着させる案をそのまま採用しない。上から接続でき、半固定抵抗の調整部にも触れられる位置を選ぶ。下面配置を残す場合にはヘッダと接続作業用の開口が必要。配線がはんだ部やピンだけで基板を支える構造にしない。
3. **IMUの接続と固定を分けて考える。** フレームへの固定面と姿勢を決め、その上方にヘッダ・コネクターの空間を確保する。コネクターや配線が上段デッキ、Picoのヘッダ／コネクター、プロペラの予約空間へ当たらないように配置する。
4. **制御系電源をESCのV/Gから取り出す案を記録する。** V→MINI360 IN+、G→IN−、調整済み5V OUT+→Pico VSYS、OUT−→Pico GND。MINI360にモーター電流を通さない。Pico GP4→ESC信号1。USBは駆動中に接続しない。通電前に極性・短絡・MINI360出力を確認する。

## v1の検証範囲への訂正

v1 CADのGY-521は21.2×16.4×4mm、MINI360は絶縁込み21×15×6mmの簡略予約だった。今回確認した上向きピンヘッダ、メスコネクター、抜き差し空間は含んでいない。既存validation.jsonの「干渉なし」はその簡略ダミーに対する結果であり、上向きヘッダ付き実物の適合を示さない。

寸法の取得とCADの更新は後で行う。現在のモーター単体試験にMPU-6050は不要。

## 配線に関する追加の配置条件

1. **プロペラへ線を出さない。** モーターの3相線はアームに沿わせて固定し、プロペラの回転範囲へ浮き上がらない経路にする。余長は機体中央の固定できる場所へ収める。CADの円筒干渉チェックは、未モデル化の線まで安全と示すものではない。
2. **電池交換の力をはんだ部へ伝えない。** 機体側XT30のリードは、ESCの端子から離れた場所で被覆部をフレームへ固定する。コネクター本体を持って抜き差しできる空間とリードの曲げを確保する。電池側リードは電池と共に外せるようにし、フレームへ固定しない。
3. **ヘッダ接続に抜け止めと配線支持を設ける。** 手持ちのメスジャンパ線は接続試験の候補。飛行時の保持は摩擦だけに頼らず、コネクター保持と線の固定位置を計画する。結束バンドで線を引き過ぎてピン・基板・半固定抵抗へ力を掛けない。電池主配線とモーター3相線へ細い信号用ジャンパ線を使わない。
4. **IMU配線を電力配線から離す。** SDA/SCLは必要な長さにとどめ、電池線・モーター3相線と長い距離を並走させない。信号とGNDを近接して配線する。モーターの電流がPico/IMUの細いGND配線を帰路として流れる構造にしない。IMU近傍に線の支持点を設け、配線でセンサの固定部を引っ張らない。
5. **挟み込み・擦れ・露出を避ける。** 支柱、デッキ、電池トレー、ねじ頭の間へ線を挟まない。基板やフレームの角で被覆が擦れる経路を避け、必要な箇所は保護する。各部の裸線・はんだ部を絶縁し、組立時と電池交換時に触れ合わないようにする。配線ラベルと固定後の極性確認も手順に含める。

次回のCADでは、これらを満たす結束バンド用の穴・溝、コネクターを保持する場所、余長を収める場所を検討する。保持構造の寸法と配線長は実物を仮配置してから確定する。

## 2026-10-05：追加写真で確認した配置条件

写真は現物の向き・端子位置の確認に使う。定規と部品には奥行き差や傾きがあるため、写真から得た高さを確定寸法としてCADへ入力しない。

1. **電池の線は短い端面から出る。** IMG_20261005_205407.jpgで、XT30側の太い赤黒線と白いバランスコネクターの線が同じ短い端面から出ている。トレーではこの端面に配線出口と曲げ空間を設ける。機体側XT30の固定部、電池側リード、未使用バランスコネクターの収納を分け、電池を線ごと取り外せる構造にする。
2. **Picoのピンは基板下側へ出る。** IMG_20261005_205347.jpgおよび205358.jpgで確認。Pico下側の接続空間を予約する。写真には接続用メスソケットを装着した状態がないため、ソケット込みの高さは未確定。
3. **GY-521は上向き8ピンの列へ個別メスコネクターを挿している。** IMG_20261005_204157.jpgおよび204232.jpgで確認。基板裏面から黒いメスコネクターの端まで約20mm前後に見えるが、写真からの概算。線の曲げとコネクターの抜き差し空間はこれに追加する。従来の部品のみ4mmの予約は使わない。
4. **MINI360は四隅の上向きピンを使う。** 同じ写真で実装部品側へ4本が出ていることを確認。写真時点ではメスコネクター未装着。その後のユーザー回答で、メスコネクター装着後の高さは基板裏面から20mmと確認した。上から接続でき、出力調整部へ触れられる配置を優先する。端子の極性表示は写真では読み取れず、ピン位置だけからIN/OUTや極性を割り当てない。
5. **ESCの配線出口を実物に合わせる。** IMG_20261005_205347.jpgの文字が読める面を上にした写真では、左に6ピンハーネス、右に電池主配線、上下にモーター用の3相パッド群がある。赤線側には+表示が見える。ハーネス、主配線、3相線の各出口に支持点と絶縁空間を設ける。信号1に対応する3相パッド群やハーネスの各線色との対応は、この写真だけでは確定しない。

上の写真確認後に尋ねた3点は、以下のユーザー回答で解消した。今回もSTEP/STL・CAD生成ソース・配布ZIPは変更しない。

## 2026-10-05：ユーザー実測・手持ち・固定試験の回答

1. **MINI360の接続後の高さは20mm。** 直前の質問で指定した「基板裏面から黒いメスコネクターの先端まで」に対する回答。線の曲げ、上からの抜き差し、出力調整の作業空間を別途確保する。
2. **面ファスナーは幅10mm×長さ125mmを1本所有。** 電池固定の第一候補とし、トレーのベルト通しは幅10mmに通し余裕を加える。実際の経路と必要な重なり長さは次回設計で確認する。電池の横滑りと前後滑りはトレーのガイドで抑える。結束バンドはユーザーが購入予定で、配線支持に使う。125mmを有効な締付け長さと決めつけない。
3. **モーターは厚さ3mmのテスト板に首下5.5mmのねじで固定できた。** 穴位置だけの確認ではなく、実際にねじ止めできたとの回答。次回の取付部は厚さ3mmと首下5.5mmの組合せを基準にする。板からの幾何学的な突出量は5.5−3.0=2.5mm（追加ワッシャー等がない場合）であり、メーカーが保証する最大挿入深さを確認した値ではない。以前の首下約3.8mmという申告を取付ねじの基準にしない。取付部の厚さやワッシャーを変更する際には、実物で再確認する。

## モーターの手持ち配線長とESCまでの距離

ユーザー申告のモーター線長は約80mm。延長を前提にせず、次回の配置でこの長さを制約に含める。

現行v1のモーター中心はX/Y=±51.265mm、ESC中心は(0,−21)mm、仮外形は30×32mm。各モーターに近い3相パッド群へ接続する想定で、パッド中心をX=±6〜12mm、Y=−37または−5mm、モーター取付面との高さ差を仮に6mmとして計算すると、モーター中心からパッドまでの直線距離はESCに近い2個で約42〜48mm、遠い2個で約69〜73mm。パッドの正確な座標と線の出口位置は未実測であり、配線経路の実長ではない。

80mmで到達する見込みはあるが、遠い側はアームに沿う経路・ESCへの立ち上がり・曲げ・はんだ付け・配線支持の余裕を含めて再確認する。次回の配置検討ではESCを機体中央へ寄せる案も比較し、80mm以内で無理なく配線できる経路を選ぶ。IMUや上向きコネクターとの干渉も併せて検討する。現時点では線を切らず、CAD形状も変更しない。
