## 機械・配線の実測と未決

| 項目 | 得られた情報 | 適用範囲・留保 |
| --- | --- | --- |
| モーター穴配置 | 正方形の一辺6.5mm側が一致 | 一致した試験穴径は2.4mm。2.2mmは当時の本番推奨で実機合格ではない |
| ESC穴配置 | 20×20mmが一致 | グロメット内穴約2mm、上下込み全高約6.2mmは報告値。部品最大高さとは別 |
| Pico接続ゲージ | 基板・4穴は一致。2.0mmスリットは入らず、3.2mmは入るが緩い | 最終スリット幅・穴脇の支持形状は未確定。左穴がつぶれかけた報告あり |
| MINI360 | 上向きピン、コネクター接続後高さ20mm | 基板裏面からコネクター先端まで。線の曲げ・挿抜・調整作業の空間を追加する |
| モーター固定 | 板厚3mm＋首下5.5mmでねじ止めできた | 旧首下3.8mmを現行基準にしない。突出量2.5mmは計算であり最大許容挿入深さではない |

手持ちモーター線は約80mm。配置からの約42〜48mm／69〜73mmは仮の直線距離で、実経路の長さではない。電池本体70×17×12mmは旧仕様書に実測と記載。重量29gは仮値で実測していない。電池線は短い端面から出る写真確認あり。[S03](../sources/snapshots/S03-wiring-plan.md)、[S05](../sources/snapshots/S05-battery.md)

PLAの2.0mm穴にはドライバーでねじ込め、2.1mmは手締めできるという報告。異なる高さ・用途の試験穴が含まれるため、その比較だけで全材料・全ねじ長へ適用しない。下面の隙間・糸引き・読めない文字も報告済み。Zオフセット原因説は未確定で、改善済みの校正値はない。[S01](../sources/snapshots/S01-fit-test.md)

## 単体回転試験の到達点

電源はバッテリー→ESC、ESC V/G→MINI360→Pico VSYS/GND。ESC V/Gはユーザー測定で電池と同電圧だった。信号はGP4・物理6番→ESC「1」。開始はGP14・物理19番とGND・物理18番のジャンパ。

| 項目 | 値・結果 |
| --- | --- |
| MINI360 | 入力7.6V、出力5V |
| Pico | 物理36番の3V3=3.27V。GP4のDC測定=0.14V |
| 旧ファームウェア | 上限1100µsで回らなかった |
| 修正版 | 上限1200µsで回転。`esc_test_pico_w_1200us.uf2`、SHA-256 `11d1e0038c6758199f7f192880b2eb31dd8bcb6f29e25a7ee68e26e34409740a` |
| 後続試験 | プロペラ付きでも回転したとの報告。飛行、推力、電流、温度、連続運転の測定はない |

修正版は停止1000µs、公称50Hz、起動待機、1秒保持で開始、1010→1200µsのランプ、開始後最大3秒停止、ジャンパを離すと停止指令。数値はコード設定。0.14VはPWM平均値と整合する目安で、パルス幅や周期の波形測定ではない。

停止確認を案内した後に「おｋ」の返答はあるが、ジャンパを離す停止と3秒自動停止の各試験結果・所要時間は個別には記録されていない。モーターはテスト板へねじ固定されている。板自体の台への固定方法は未回答で、プロペラが回ったことから固定の安全性や強度を認定しない。[C075〜C083](../sources/conversation.md#c075)、[S08](../sources/snapshots/S08-motor-test.md)

## 原会話・保存資料との差

初期回答は2.2mmのモーター穴を採用値のように列挙したが、後の記録で「実測合格は2.4mm、2.2mmは未検証推奨」と区別した。初期回答のZオフセット主因という断定も、保存記録では推定へ訂正されている。

Pico 2 WHのヘッダ自体は初期から認識していた。ヘッダを全面的に忘れたという単純化ではなく、接続後の通り道・余裕・支持・上向き基板の占有体積が十分でなかった事例として読む。
