# レビュー依頼：Skill「tsukurumae」の「目的から考える」の節

## お願いしたいこと

AI エージェント（Claude Code / Codex）に読ませる指示書（Agent Skill）の、ある1つの節の文章を考えてほしい。
これまで何度か書き直したが、ユーザーの意図に届いていない。下の資料を読み、ユーザーが求めていることを満たす節の文案を出してほしい。あわせて、なぜその書き方にしたかと、これまでの案のどこがずれていたかの見立ても書いてほしい。

## 前提（最低限）

- **tsukurumae とは**：ユーザー本人だけが使う Agent Skill。ハードウェア・ソフトウェアの開発を始めるときに `/tsukurumae` と打つと、AI がユーザーと一緒に要件定義をする。合意したら、要件定義書と、その案件専用の指示書を作る。作業は別の会話で、その指示書を読んだ AI が進める。
- **tsukurumae の目的**：ユーザーの開発を楽にすること。無駄な生成と無駄なターンをなくすこと。そのために、最初の要件定義をしっかりやる。tsukurumae は目的ではなく手段。
- **Skill の書き方の方針（ユーザーと合意済み）**：
  - 細かいチェック項目や手順を並べない。考え方を中心に、軽く書く。細かくすると、AI は決まった提案と検証しかできなくなる。
  - 今回の案件（tsukurumae 自身の開発）など、特定の案件に寄った言葉で書かない。どんな案件にも使える、一段メタな書き方にする。
  - 日本語。短い文。
- **ユーザーと合意済みの関連方針**：
  - 作ること自体が目的なら（例：趣味でドローンを作りたい）、既製品を勧めない。目的に沿うなら、作らない選択肢を出してもよい。
  - 決めるのはユーザー。AI は理由を付けて提案する。
  - 要件定義の段階では、考えを引き出す開いた質問をしてよい（数の上限なし）。
