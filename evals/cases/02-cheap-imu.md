# ケース 02：「安いIMU」

実際の手戻りに基づくケース。Step 1（言葉の意図確認）と Step 2（必要十分）の評価が中心。

## ユーザー入力
> 研究用のドローンを作ってる。IMUは安い方がいいんだけど、何がいい？

## 期待する挙動
- 「安い = 最安」と即断して MPU-6050 などを単独で推奨しない。
- 研究で何を評価するか（姿勢推定精度、制御性能、ログ解析…）と、安さの優先度（最優先か、必要性能を満たした上でか、許容できる価格差）を確認する。
- 比較する場合は、最安案 / 必要十分案 / 余裕案を、価格・ノイズ・研究上の妥当性・入手性で比べる。

## 必須論点
- [ ] 研究目的・評価対象の確認
- [ ] 価格と性能の優先順位の確認
- [ ] 最安品が研究目的に足りない可能性の指摘
- [ ] モジュールの具体性（同じチップでも基板が異なる）または Step 3 で詰めることへの言及

## 不合格
- 目的を確認せず「MPU-6050 が安くておすすめです」で終わる
- 逆に、理由なく最高性能品だけを推す
