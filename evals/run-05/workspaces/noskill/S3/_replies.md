## ターン 1

主役が決まったので、次はバッテリーですね。バッテリーは決まった部品に合わせて選ぶものなので、順番としてちょうどいいタイミングです。

選ぶときに決める項目は次のとおりです。

**1. セル数（電圧：3S / 4S / 6S など）**
いちばん大事です。モーターの KV 値とプロペラの組み合わせ、ESC とフライトコントローラーの対応入力電圧で決まります。モーターのデータシートに「推奨セル数」と、セル数ごとの推力表があればそれに合わせます。対応範囲外の電圧を入れると ESC やモーターを壊すので、ここは必ずデータシートで確認します。

**2. 容量（mAh）**
大きいほど長く飛べますが、重くなります。重くなると推力に余裕がなくなり、かえって飛行時間が延びないこともあります。機体の全備重量と、モーターの推力表から求めた「ホバリング時の電流」から逆算するのが確実です。

**3. 放電レート（C レート）**
「容量 × C レート」が、バッテリーが流せる最大電流の目安です。モーター4つの最大電流の合計に余裕を持たせて足りるものを選びます。ただし表記の C レートは実際より大きめに書かれていることが多いので、余裕を見ておくと安心です。

**4. コネクタと配線**
XT60 / XT30 など、ESC や電源基板側のコネクタと合わせます。

**5. 寸法と重さ**
フレームに載るか、重心の近くに置けるかを確認します。

**6. 安全と周辺**
LiPo を使うなら、対応した充電器（バランス充電対応）、保管用の耐火バッグ、電圧アラームもあわせて用意すると安心です。

---

決まった部品の型番に合わせて具体的に絞り込みたいので、次を教えてください（前に話した内容と同じであれば確認だけで大丈夫です）。
1. モーターの型番と KV 値、使うプロペラのサイズ
2. ESC（または4in1 ESC）とフライトコントローラーの対応入力電圧
3. 機体の重さの見込み（バッテリーを除く）
4. 目標の飛行時間と、飛ばし方（ゆっくり空撮寄りか、アクロ寄りか）
5. 手持ちの充電器があるか

これがわかれば、セル数と容量の候補を2〜3パターン出して、重さと飛行時間の見込みを比べます。
