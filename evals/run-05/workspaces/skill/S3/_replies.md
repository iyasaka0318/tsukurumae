## ターン 1

段階 3／6：周りの成り立ち（電源＝バッテリー）　次：セル数と容量を主役の条件から決め、全体の構成表を出す

バッテリーは、決まった主役（フライトコントローラーとモーター）から逆算して決めます。好みで選ぶ部分は少なく、ほとんどが主役の仕様と飛び方で決まります。

なお、この会話の作業フォルダーには `TSUKURUMAE_REQUIREMENTS.md` と `TSUKURUMAE_LEDGER.md` が見当たりませんでした。決まった部品の型番や要件の数値を、記憶で補って決めるのは避けたいので、どちらかを教えてください。
- 2つのファイルがある場所（別のフォルダーなら、そのパス）。読めばすぐ進めます。
- または、下の「決める順番」の (1)〜(3) に関わる値（モーターの型番と KV、ESC の型番、フレームのサイズとプロペラ、目標の飛行時間）。

### バッテリーで決めること（決める順番）

1. **セル数（電圧）**：モーターの KV とプロペラの組み合わせ、ESC とフライトコントローラーの対応電圧で、ほぼ決まります。ここは選ぶものではなく、主役の仕様から決まるものです。満充電のときの電圧（1セル 4.2V）が、ESC・フライトコントローラー・カメラなど電池から直接電気を取る部品の許容電圧を超えないかを確かめます。
2. **流せる電流（C レート）**：モーター4つの最大電流の合計に、余裕を持たせて足りるか。足りないと、急に上昇したときに電圧が大きく下がり、フライトコントローラーがリセットしたり、電池が傷んだりします。
3. **容量（mAh）と重さ**：容量を増やすと飛行時間は延びますが、電池が重くなって推力の余裕が減ります。「機体の総重量に対して推力が何倍あるか」を保ちながら、目標の飛行時間に近い容量を選びます。容量と重さは、表で比べて出します。
4. **コネクター**：ESC 側のコネクターの種類に合わせます（電流の大きさでも選ぶ種類が変わります）。
5. **載せ方**：搭載位置（重心）、固定（ストラップとすべり止め）、線の出口、交換のしやすさ。

### 決めるための質問（4つ）

1. **主役の型番**（上のとおり、ファイルの場所か型番を教えてください）
   - 効くこと：セル数・C レート・コネクターが全部ここで決まります。
2. **目標の飛行時間はどのくらいですか**。要件定義書に書いてあれば、それを使います。
   - 効くこと：容量と重さの釣り合い。
   - 推奨：特に希望がなければ、趣味で練習に使うなら「1本で数分飛べて、何本か持って行って交換する」運用を勧めます。1本を大きくするより、推力の余裕を残せて、墜落したときの損害も小さいからです。
3. **手持ちの電池と充電器はありますか**（ラジコン用の LiPo、充電器の型番）。
   - 効くこと：手持ちの充電器が対応するセル数・コネクターに合わせると、追加の買い物が減ります。
   - 推奨：充電器がなければ、バランス充電ができるものを電池と一緒に選びます。
4. **電池をどこで保管・充電しますか**（自室、作業場など）。
   - 効くこと：LiPo は過充電・過放電・衝撃で発火することがあるので、保管用の耐火袋や、充電中に離れない運用を、場所に合わせて決めます。

答えをもらう前に進められることとして、主役の型番が分かり次第、メーカーの資料で対応電圧・最大電流を調べ、候補の電池（セル数・容量・C レート・重さ・コネクター・価格）の比較表を作ります。価格と在庫は調べた日付を付けて出します。
