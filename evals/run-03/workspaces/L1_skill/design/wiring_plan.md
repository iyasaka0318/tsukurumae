# 電源・配線の仮案（2026-10-06）

**状態：仮案。** ピン番号は Pico W のピン配置図で照合してから確定する。値の出典が「記憶」のものは未確認。

## 電源の流れ
```
2S LiPo ──┬── ESC（4in1）の電源入力 ── モーター×4
          └── MINI360 IN+ / IN-
                 └─ OUT（5V に調整）──[ダイオード？ A4]── Pico W VSYS
                                       Pico W 3V3(OUT) ── GY-521 VCC
GND：電池 − / ESC GND / MINI360 GND / Pico W GND / GY-521 GND を共通にする
```

## 信号（仮の割当）
| 用途 | Pico W 側（仮） | 相手 | 備考 |
|---|---|---|---|
| I2C SDA | GP4 | GY-521 SDA | I2C0。GY-521 のプルアップの接続先電圧を確認する |
| I2C SCL | GP5 | GY-521 SCL | |
| ESC M1〜M4 信号 | GP10〜GP13（仮） | ESC の信号パッド | プロトコル（Q5）で使い方が変わる。PWM のスライス割当を確認 |
| ESC 信号の GND | 近くの GND ピン | ESC の GND パッド | |
| 電源 | VSYS | MINI360 OUT | A4 を確認してから接続 |

- Pico W は無線チップ用にいくつかの GPIO を内部で使っている。割当はピン配置図で避けていることを確認する（未確認）。
- 提案（必須ではない）：電池電圧を抵抗分圧で ADC（GP26 など）に入れると、電圧低下での自動着陸や警告に使える。

## 接続前に確かめること
1. MINI360 を Pico W につながずに電池（または同等の電源）を入れ、出力をテスターで測りながら可変抵抗で 5V に合わせる。
2. Pico W データシートの給電の章で、VSYS に外部電源を入れたまま USB を挿してよい条件を確認する（A4）。
3. ESC の信号パッドの位置と GND パッドを ESC の資料で確認する（Q5）。
