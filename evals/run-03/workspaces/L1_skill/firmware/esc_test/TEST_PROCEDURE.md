# esc_test v0.1 試験手順（プロペラなし・モーター1個）

## 確認できていること / いないこと
- 作成したのはソースのみ。**ビルド・実機動作・出力波形は未確認。**
- MAX_US=1100 で ESC が回り始めるかは未確認（ESC の始動点・設定・プロトコルに依存。Q5）。
- ESC が DShot 専用のファーム（例：Bluejay）の場合、50Hz PWM には反応しない（未確認）。

## 配線（この試験だけ）
| Pico W | 相手 |
|---|---|
| GP10（物理ピン14） | ESC の M1 信号パッド |
| GND（物理ピン13） | ESC の GND パッド |
| GP15（物理ピン20） | 試験用ジャンパー線（もう一端は GND 物理ピン18 に挿す/離す） |
| USB | PC（Pico W の電源はこれだけ） |
- ピン番号は Pico W のピン配置図で照合してから挿す。
- **この試験では MINI360 を VSYS につながない**（USB と同時に給電した場合の扱いが未確認：A4）。
- ESC の他の信号パッド（M2〜M4）は何もつながない。

## 準備
1. プロペラが付いていないことを確認。モーター軸に何も付けない。
2. モーターを机に固定する（テープや万力で台に。手で持たない）。ESC も固定し、モーターの線が回転部に触れないようにする。
3. 電池のコネクターは、すぐ抜ける位置に置く（非常停止の手段）。

## 手順
1. 電池を外したまま、Pico W を BOOTSEL を押しながら PC に挿し、`esc_test.uf2` をコピーする。
2. PC のシリアルモニターで `pin=open armed=1 pulse_us=1000` が出ることを確認する。
3. 電池を ESC につなぐ。ESC の起動音を聞く（起動音のパターンで、信号を認識したかが分かる。意味は ESC の資料で確認）。
4. ジャンパーを GND（ピン18）に挿す → 1秒かけて 1100us まで上がる。シリアルに `pulse_us=1100` と出る。
5. ジャンパーを離す → 即 1000us に戻り、停止する。
6. 終わったら電池を先に外し、次に USB を外す。

## 停止の手段
- 通常：ジャンパーを離す（離す・抜けるで停止）
- 非常：電池のコネクターを抜く

## 記録してほしいこと
- 手順3の起動音（回数・長さ）
- 手順4で回ったか（回った/震えただけ/無反応）
- 回った場合：ジャンパーを離してから止まるまでの様子
- 回らない場合は値を上げる前に教えてください（ESC のプロトコル・始動点を先に確認します）
