# 自作ドローン（Pico W） 台帳
最終更新: 2026-10-06

## 概要
- 作るもの: 小型クアッドコプター（機体・電装・ファームウェア・3Dプリントフレーム）
- 分野: 両方（ハード＋組込みファームウェア）
- 用途: 趣味
- 目的: 手持ち部品で飛ぶドローンを作る（詳細は Q1）
- 成功条件: 未決（Q1。推奨案：室内で数十秒、姿勢を保ってホバリングでき、操縦で離着陸できる）
- 優先順位: 未決（仮：安全に試せること > 手持ち部品の活用 > 性能）

## 仮定
| ID | 内容 | 確かめる方法 | 外れたときの影響 |
|---|---|---|---|
| A1 | フライトコントローラーのファームウェアは自作する（既製 FC ファームではない） | Q1 で確認 | 進め方全体が変わる |
| A3 | MINI360 の出力は出荷時に 5V とは限らず、可変抵抗で合わせる必要がある | 購入品の資料確認＋テスターで実測 | 合わせずに接続すると Pico W を壊すおそれ |
| A4 | Pico W の VSYS に外部電源を入れ、同時に USB を挿す場合、VBUS と外部電源がぶつからないようダイオードが必要 | Pico W データシートの給電の章で確認する（未確認） | USB 側や PC へ逆流、MINI360 への逆流 |
| A5 | （一部確認済み → T1）ESC は 50Hz の標準 PWM で回る。1100us では回り始めない（推定） | ESC のファーム種別・設定を確認、esc_test で試験 | 回らない（DShot 専用ファームや始動点が上なら）。値を上げる前に原因を切り分ける |
| A2 | 開発言語は C/C++（Pico SDK または Arduino-pico）で、制御ループの周期を優先する | Q1 の答え次第で見直し | ループ周期・書き方が変わる（中） |
