## ターン 1

### 理解したこと
- 手持ち部品で小型クアッドコプターを作る趣味の案件です。機体（3Dプリントフレーム）、電装、ファームウェアの全部にかかわります。
- フライトコントローラーは市販の FC ではなく Pico W なので、**姿勢制御のファームウェアを自分で書く前提**だと推定しています（違えば Q1 で教えてください）。
- 段階は構想段階（部品は手持ち、計画書はまだない）と判断しました。

### 見つけた論点
1. **操縦の手段が部品リストにありません。** 受信機が無ければ、Pico W の Wi-Fi で PC やスマホから操縦する形になります。その場合は「通信が切れたらモーターを止める」処理が安全の要になります。
2. **プロペラと、モーターの KV が決まっていません。** 1104 は KV の違う品が多く、2S での推力とプロペラの径が KV で変わります。プロペラ径が決まらないとフレームのモーター間の距離が決まらないので、CAD より先に必要です。
3. **Pico W の給電経路が未確認です。** この ESC に 5V 出力（BEC）があるかどうかで、レギュレーターを追加するかが変わります。モーターの負荷で電圧が下がり Pico W がリセットされると、飛行中に制御が止まります。
4. **ヘッダー付きの Pico W をジャンパー線でつなぐと、振動で抜けるおそれがあります。** 飛行中に ESC への信号が抜けるのは危険なので、配線方式でフレームの高さと固定方法も変わります。
5. **MPU-6050 は振動の影響を受けやすいです。** 取付の位置と防振、それにソフト側のフィルターが必要です。GY-521 を 3.3V で使えるかどうか（基板上のレギュレーターの電圧降下）もこれから資料で確認します。
6. **ESC のプロトコル（PWM／OneShot／DShot など）と、ESC 側のファームウェアの種類**を確認し、Pico W から出す指令が ESC の反応する範囲に入るようにします。

### 質問（5つ）
| ID | 質問 | 何に効くか | 推奨案 |
|---|---|---|---|
| Q1 | 何ができたら完成ですか。FC のファームウェアはご自分で書きますか | 成功条件、ソフトの規模、試験の計画 | 特に希望がなければ「自作ファームで、室内でホバリングと離着陸ができる」を最初の目標にします |
| Q2 | 操縦方法：手持ちの送信機と受信機はありますか。無ければスマホと PC のどちらから操縦したいですか | 追加部品、ピンの割当、通信が切れたときの処理 | 受信機が無ければ、PC から Wi-Fi（UDP）で送り、一定時間届かなければ自動で停止する方式 |
| Q3 | モーターの KV（ラベルか購入ページ）と、プロペラの手持ちはありますか | プロペラ径 → フレーム寸法、推力の概算 | 購入ページのリンクかラベルの写真をください |
| Q4 | Pico W のヘッダーはどちら向きに出ていますか（部品面の反対側か）。配線はジャンパー線とはんだ付けのどちらにしたいですか | フレームの高さ、固定方法、飛行中に抜けないか | ESC の信号と電源ははんだ付け、IMU も短い線ではんだ付け |
| Q5 | ESC と電池の購入ページ（またはラベル写真）、LiPo 対応の充電器はお持ちですか | ESC の入力電圧範囲・BEC・プロトコル・取付穴、電池のコネクター | リンクをもらえれば、こちらで仕様を調べます |

### 答えを待たずに進められること
- **資料の調査**：Pico W のピン配置と VSYS の許容入力、MPU-6050 と GY-521 の電源・I2C、1104 モーターの一般的な取付穴、HAKRC 15A 4in1 の仕様（型番が特定できたら）を調べます。結果は「メーカー公称」として台帳に書きます。調べていない値は未確認のまま扱います。
- **重量と推力の概算の枠組み**：各部品の重量を変数にした表を作っておき、KV とプロペラが分かったら数値を入れます。
- **ベンチでのファームウェア試作（モーターなし）**：Pico W と MPU-6050 を机上でつなぎ、I2C で角速度と加速度を読み、姿勢を推定して表示するところまでは、ESC や電池なしで進められます。ESC への信号出力も、ESC をつながずにオシロスコープかロジックアナライザーで確認する段階までなら進められます。
- **フレーム**：プロペラ径が決まるまで本番の CAD は確定しません。その代わり、モーターの取付穴とネジが PLA でどう収まるかを確かめる小さな試験片なら、取付穴の寸法が分かれば先に印刷できます。

### 安全面（今後の段階）
モーターの試験は「プロペラなし → 機体を固定してプロペラあり → 自由飛行」の順に分けます。各段階の前に、止める手段（アームを解除する操作、通信が切れたときの自動停止、電池コネクターを抜く位置）を具体的に決めてから進めます。

### 台帳
`TSUKURUMAE_LEDGER.md` を作り、上の論点・質問・仮定（自作ファーム、C/C++ で書く）・リスクを記録しました。また、`CLAUDE.md` と `AGENTS.md` に、台帳を読んで作業するよう1行を追加しました。

## ターン 2

了解しました。4点を決定として台帳に入れ（D1〜D4）、電源と配線の仮案を `design/wiring_plan.md` に書きました。

### 決定を受けて変わること
- **ヘッダー下向き＋ジャンパー線（D1）**：Pico W の下に、ピン＋ジャンパーのハウジング＋線の曲がりの高さが必要です。この高さは資料に載っていないので、実測をお願いします（Q6）。振動でジャンパーが抜けるリスクは残るので、ハウジングをまとめてテープか結束バンドで固定し、線を短くする前提でフレームに固定点を設けます。
- **組み立て後も USB で書き込む（D2）**：フレームでは、USB プラグを挿した状態の長さと抜き差しの空間を Pico W の USB 側に確保します。もう一つ大事なことがあります。**書き込み中や書き込み直後は、電池をつないだままだとモーターが回るおそれがあります。** 書き込むときはプロペラを外すか電池を外す、ファームウェアは必ずアーム解除の状態で起動する、の2つをルールにします（R7）。
- **電池をベルトで固定（D3）**：ベルト通し穴の幅と位置を決めるため、電池の寸法とベルトの幅が必要です（Q7）。重心が機体の中心に来るように、搭載位置は重量の概算と一緒に決めます。
- **MINI360 → VSYS（D4）**：ESC の BEC は不要になりました。接続の前に次の2つを確かめます。
  1. MINI360 は可変抵抗で出力を合わせる品が多く、届いた時点で 5V になっているとは限りません（A3）。**Pico W につなぐ前に**、MINI360 だけに電池をつなぎ、出力をテスターで測りながら 5V に合わせてください。
  2. VSYS に外部電源を入れたまま USB を挿すと、USB の 5V と MINI360 の 5V がぶつかる可能性があります。Pico W のデータシートの給電の章で、ダイオードを入れる必要があるかを確認します（A4、まだ確認していません）。D2 で USB を挿したまま使う場面があるので、ここは配線を確定する前に必要です。

### 新しい質問

| Q6 | ジャンパー線を挿した状態で、Pico W 基板の裏面から線が曲がり終わるまでの高さ。線は真下に出しますか、横に曲げますか | Pico W の台の高さ、フレームの厚み | 挿した状態で定規を当てて測ってください |
| Q7 | 電池の寸法（縦・横・厚さ）、ベルトの幅、電池の線が出る向き | ベルト通し穴の位置と幅、重心 | 購入ページか実測 |

### 前回からまだ答えをもらっていない点
- **Q2（操縦方法）と Q3（モーターの KV、プロペラ）**は、ピン割当とフレーム寸法が決まらないので、引き続き教えてください。
- Q1（完成の条件）は、「自作ファームで室内でホバリングと離着陸」で仮に進めます。
- Q5（ESC と電池の購入ページ）は、ESC のプロトコルと取付穴の確認に使います。

### 進めたこと
- `design/wiring_plan.md`：電源の流れ（電池 → ESC／MINI360 → VSYS、GND 共通）と、ピン割当の仮案（I2C は GP4/GP5、ESC 信号は GP10〜13）を書きました。どちらもピン配置図で照合してから確定する**仮案**です。
- 必須ではない提案として、電池電圧を抵抗分圧で ADC に入れ、電圧が下がったら警告や着陸に使う案も書いておきました。

## ターン 3

試験ファームを作りました。**作ったのはソースだけで、ビルドも実機での動作も確認していません。**

### 作ったもの（`firmware/esc_test/`）
- `main.c`：Pico SDK（C）で書いています。
  - 起動直後から、50Hz で 1000µs（停止）を出し続けます。
  - GP15 を GND につなぐと、1100µs まで上げます。いきなり上限にせず、1秒かけて上げます（`RAMP_MS`、0 にすれば即座に上限）。
  - GND から離すと、すぐに 1000µs に戻ります。GP15 は内部プルアップなので、ジャンパーが抜けた場合も停止側になります。
  - 起動したときに既に GND につながっていたら、一度離すまで回しません。書き込み直後に勝手に回るのを防ぐためです（R7）。
  - 上限を超えるパルスは出さないようにしています。値はすべてファイル先頭の定数（`MAX_US` など）にまとめてあります。
  - USB シリアルに、ピンの状態と今出しているパルス幅を表示します。
- `CMakeLists.txt` と `build_commands.md`：ビルドの方法です。PC の bash で、Pico SDK を入れた環境で実行します。
- `TEST_PROCEDURE.md`：配線、準備、手順、止め方、記録してほしいことをまとめました。

### 配線（この試験だけ。ピン番号はピン配置図で照合してから挿してください）
- GP10（物理ピン14）→ ESC の M1 信号、GND（物理ピン13）→ ESC の GND
- GP15（物理ピン20）に試験用のジャンパー線をつなぎ、もう一端を GND（物理ピン18）に挿すと回り、離すと止まります。
- **Pico W は USB からだけ給電してください。MINI360 は VSYS につながないでください。** USB と同時に給電したときの扱い（A4）をまだ確認していないためです。
- 非常時は電池のコネクターを抜きます。電池はすぐ抜ける位置に置いてください。
- プロペラなしでも、モーターは手で持たず、テープか万力で台に固定してください。

### 先に伝えておきたいリスク：1100µs で回らない可能性があります
- ESC は、指令がある値を超えるまで回り始めません。この ESC の始動点が 1100µs より上だと、正しく配線しても回りません。始動点は ESC の設定次第で、まだ確認していません（A5）。
- この ESC が DShot 専用のファームウェア（Bluejay など）だと、50Hz の PWM にはまったく反応しません。これもまだ確認していません。
- 上限 1100µs はご指定どおりにしてあります。**回らなかったときは、値を上げる前に教えてください。** 起動音と ESC の設定から、配線・プロトコル・始動点のどれが原因かを先に切り分けます。値は `MAX_US` を書き換えるだけで変えられます。
- 確認のため、ESC の購入ページ（Q5）があると助かります。こちらでもプロトコルと設定を調べます。

### 試験後に教えてほしいこと
1. 電池をつないだときの ESC の起動音（回数・長さ）
2. GND につないだとき：回った／震えただけ／反応なし
3. 回った場合：離してから止まるまでの様子

台帳には、試験の条件（D5）、仮定 A5（PWM を受け付けて 1100µs で回る）、リスク R8（USB と MINI360 の同時給電）を追加し、作業の状態を「作成済み・ビルド未確認・実機未確認」にしました。

## ターン 4

結果を台帳の試験記録に T1・T2 として書きました。まとめは次のとおりです。

### ユーザーの報告
- 上限を 1200µs にしたら、モーターが回った（プロペラなし）。
- その後プロペラを付けても回った。「おｋ」。

### ファームウェアの状態
- 試験したのは esc_test v0.1 の上限（`MAX_US`）を 1200µs に変えた版です。変更は手元で行ったものと理解しています。作業フォルダーのソースは 1100µs のまま変えていません。
- 50Hz、停止 1000µs、GP15 を GND につなぐと 1秒かけて上限まで上げる、という動きは v0.1 のままです。

### 報告から分かること
- この ESC は 50Hz の標準 PWM を受け付けて、1200µs でモーターが回った。→ 「DShot 専用で PWM に反応しない」という可能性は消えました。
- 1100µs では回らなかったと読み取りました（文面からの推定です）。始動点は 1100〜1200µs のどこかにあると考えられますが、正確な値は測っていません。
- 上限を 1200µs に変えたことは、決定 D6 として記録しました。

### まだ確認していないこと
「回った」と「おｋ」から分かるのは**回転したことだけ**です。次の点は確認済みにしていません。
- ジャンパーを離したときに止まったか、止まるまでの時間
- 回転方向と、プロペラの向き（正転・逆転用）が合っているか
- 推力（ホバリングに足りるか）
- プロペラ付きのとき、何を何に固定していたか（固定の安全性）
- モーターや ESC の発熱
- 残りの3つのモーターと ESC の3チャンネル
- 実際の出力波形（測定していません）

### 短く確認させてください（Q8）
プロペラ付きの試験では、モーター（または機体）を何に固定していましたか。ジャンパーを離したら止まりましたか。次にプロペラ付きで試験するときの条件を決めるのに使います。

### 次の候補（提案です。まだ何も変えていません）
1. 4チャンネル分の確認：モーターごとに回転方向と停止を、プロペラなしで確かめる。
2. 始動点を測る：上限を 10µs ずつ変えて回り始める値を探す。制御の最小出力を決めるのに使います。
3. プロペラ付きの試験：固定の方法、止める手段、周りに何もないことを先に決めてから進めます。

## ターン 5

計画だけを直しました。CAD・コード・配線案は変えていません。

先にお伝えしておくと、**このプロジェクトでは、まだフレームの CAD 案を作っていません。** 台帳でも本番の CAD は「未着手」のままです。そのため「前の CAD 案に入っていない」というより、これから作る CAD の確定条件に、この2つが入っていなかった、という状態です。別の場所に CAD 案をお持ちでしたら、ファイルを渡していただければ照らし合わせます。

### 台帳に反映したこと
- **事実（K5、K6）**：GY-521 と MINI360 はピンが上向き。接続はジャンパー線だと推定しています（Pico W と同じ方式）。違えば教えてください。
- **本番 CAD の確定条件に追加**：
  - GY-521 と MINI360 の、ジャンパー線を挿した状態の上方向の高さと、線の出口
  - MINI360 の可変抵抗に、組み立て後もドライバーとテスターが届くこと
  - 部品の上に重ねるもの（電池・ベルト）が、ジャンパー線を押さないこと
- **リスク**：
  - R9：上向きのジャンパー線の上に電池やベルトが重なると、線が押されて抜けたり、IMU に力がかかったりします。部品の上に空間を残すか、電池を別の位置に置きます。
  - R10：MINI360 の可変抵抗が振動や接触で回ると、出力電圧が変わります。調整後の固定を検討し、組み立て後も測れる位置に置きます。

### 質問（Q9）
GY-521 と MINI360 に、ジャンパー線を挿した状態で、基板の裏面から線が曲がり終わるまでの高さを測ってもらえますか。線はどの辺の方向に出したいですか（特に希望がなければ、機体の中心側に出す前提で計画します）。Pico W の下方向の高さ（Q6）と一緒に測ってもらえると、部品を何段に重ねるかを一度に決められます。

## ターン 6

フレームの**仮モデル**を作りました：`cad/frame_v0_1.scad`（OpenSCAD）。
寸法の多くがまだ分かっていないので、それらは名前付きの変数にして「仮」と書いてあります。実測値が来たら、ファイル先頭の変数を差し替えるだけで直せます。**レンダリングも印刷もしていないので、形が正しく出るかもまだ確認していません。** 本番の印刷は、下の条件が揃ってからにしてください。

### 配置（仮に決めたもの・D7）
- **上面**：前から ESC → 中央に GY-521 と MINI360 → 後ろに Pico W
  - IMU（GY-521）を機体の中央に置きました。
  - Pico W はピン下向きなので、ジャンパー線の高さ分のスタンドオフ（`PICO_UNDER_H`、仮に 12mm）の上に載せます。USB は後ろの端に向けて、プラグを挿す空間（`USB_PLUG_L`）を確保しています。
  - GY-521 と MINI360 は取付穴が未確認なので、両面テープと結束バンドで留める前提で、結束バンドの穴を開けています。上向きピンの上には何も重ねません。
- **下面**：電池をベルトで留めます。ベルトは下面のループに通るので、上面の部品を押しません（R9 への対策）。
- **モーターの位置**：プロペラの円が本体に重ならないように計算しています（部品の高さを考えない、安全側の計算です）。

### 既定の仮の値で計算した寸法（計算値。すべて仮の値から出したもの）
本体 106×48mm、モーター間の距離は前後 71mm、左右 125mm、対角は約 144mm です。左右に広い形になりました。プロペラ径と部品の高さが分かれば、小さくできる可能性があります。

### `PART` の切り替え
- `"preview"`：フレームに、部品の占有範囲・USB プラグ・電池・プロペラ円を半透明で重ねた確認用の表示です。
- `"frame"`：フレームだけを出力します（仮）。
- `"motor_gauge"`：モーター取付穴の試験片です。穴径 2.0／2.2／2.4mm の3種類を並べています。

### 本番を確定するのに足りないもの（台帳の作業の状態にも書きました）

| `MOTOR_HOLE_SPACING` | 9mm | 1104 の取付穴の間隔（購入ページか現物） |
| `ESC_BOARD`, `ESC_HOLE_SPACING` | 27mm, 20mm | ESC の外形と取付穴（Q5） |
