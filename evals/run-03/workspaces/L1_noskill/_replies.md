### 配線前に確認が必要な点（壊さないため）
- **電源**：2S は満充電で約 8.4V になります。Pico W の VSYS や GY-521 に直接つなぐと壊れる可能性があります。HAKRC の 4in1 ESC に 5V の BEC（電源出力）が付いているかを、お手持ちの型番のデータで確認する必要があります。なければ別途 5V の降圧レギュレーターが必要です。
- **ESC の信号**：その ESC が受け付ける信号（PWM／Oneshot／DShot など）と、ESC のファームウェア（BLHeli_S / Bluejay など）を確認します。Pico は PIO で DShot も PWM も出せますが、どちらにするかで実装が変わります。信号レベルは Pico の 3.3V で受けられるかも確認ポイントです。
- **ESC の対応電圧と電流**：2S に対応しているか、15A が 1104 の電流に足りるか（多くの場合は足りると思いますが、モーターの仕様で確認します）。
- **GY-521**：基板に 3.3V レギュレーターが載っているので、I2C は Pico の 3.3V で接続できるはずです。電源を 3.3V から取るか 5V から取るかは基板の版によって違うので、手元の基板を確認してください。

### フレーム（SV06・PLA）で先に決めること
- モーターのネジ穴ピッチと ESC の取付穴（20×20 か 16×16 か等）を、**実物をノギスで測ってから** CAD に入れるのがおすすめです。ここを推測で作ると刷り直しになりがちです。
- プロペラのサイズからアームの長さ（プロペラ同士が干渉しない距離）を決めます。
- PLA は軽くて造形しやすい反面、衝突で割れやすく、夏の車内のような高温では変形します。最初は割れても刷り直せばいい、くらいの気持ちで試すとよいです。

## ターン 2

了解です。方針は把握しました。それぞれ、フレーム設計と配線に効いてくる点を挙げます。

### 1. Pico はピン下向き＋ジャンパ線
- **振動で抜けやすい**のが一番の心配です。ドローンはモーターの振動が常にかかるので、ジャンパ線（デュポン端子）は飛行中に抜けたり接触不良になったりしがちです。特に ESC の信号線や電源線が抜けると墜落につながります。対策としては、コネクタをホットボンドやテープで固定する、ハウジングをまとめて 1 本の多ピンコネクタにする、などがあります。最終的には重要な線（電源・ESC 信号・I2C）だけでもはんだ付けを検討するとよいと思います。
- **フレームの高さ**：ピンが下向きで、さらにジャンパ線の端子と曲げ代が下に出るので、Pico の下に必要な空間がかなり大きくなります。実物にジャンパ線を挿した状態で高さを測ってから、スタンドオフの高さを決めましょう。
- **重量**：ジャンパ線と端子は小型機では意外と重さになります。線は必要な長さに切りそろえるのがおすすめです。

### 2. 組み立て後も USB を使う
- フレームの設計で、**Pico の micro USB 端子にケーブルが挿さる穴・すき間**を確保します。ケーブルのプラグ部分は端子より大きいので、手持ちのケーブルのプラグ寸法を測っておくと確実です。
- **USB と MINI360 から同時に給電される問題**：Pico は VBUS（USB の 5V）がダイオード経由で VSYS につながっています。MINI360 の出力を VSYS に直結した状態で USB を挿すと、USB の 5V が MINI360 の出力側に流れ込む可能性があります。Pico のデータシートでは、VSYS に外部電源をつなぐ場合にショットキーダイオードを入れる方法が紹介されていたはずなので、該当箇所を確認して回路に入れることをおすすめします（データシートの記述は確認します）。
- **安全面**：USB で書き込み中に電池がつながっていると、書き込み直後のプログラムでモーターが回る可能性があります。USB 作業時は「プロペラを外す」か「電池を外す」をルールにしましょう。

### 3. 電池をベルトで留める
- フレームに**ベルトを通すスリット**を設けます。手持ちのベルトの幅と厚みを測って、少し余裕を持ったスリット寸法にしてください。
- 電池の位置は**重心がモーター 4 つの中心に来る**ようにします。前後にずらせる長さで置けると、組み立て後に調整できます。
- 電池がずれないよう、滑り止めのパッド（ゴムシートなど）を貼ると安心です。ベルトだけだと衝撃で電池が飛び出すことがあります。
- 電池のケーブルとコネクタの取り回し（どちら向きに出るか）も、ESC の電源入力の位置に合わせて決めておきましょう。

### 4. MINI360 で 5V を作って VSYS へ
- 構成としては妥当です。2S（最大約 8.4V）は MINI360 の入力範囲内のはずです。
- **接続前に必ず出力電圧を合わせる**：MINI360 は半固定抵抗で出力電圧を調整するタイプで、出荷時の電圧が 5V とは限りません。電池をつないでテスターで 5V 前後になっていることを確認してから Pico につないでください。VSYS の上限（データシートでは 5.5V）を超えると壊れます。
- **半固定抵抗が振動で回るのを防ぐ**：調整後に少量の接着剤やマスキングで固定するとよいです。
- **GND の共通化**：ESC の GND、MINI360 の GND、Pico の GND は全部つなぎます。ESC の信号は GND が共通でないと正しく伝わりません。
- **ESC に BEC がある場合**：前回お聞きした「ESC に 5V 出力があるか」が分かれば、MINI360 が不要になるかもしれません。どちらを使うにしても、2 つの 5V 出力を同時につながないようにしてください。

### まだ教えてほしいこと（前回からの続き）
- 何をしたいドローンか（室内ホバリング／屋外／FPV）
- 操縦方法（Pico W の Wi-Fi か、RC 受信機か）
- ESC とモーターの型番（モーターの KV、プロペラのサイズ）
- 手元の測定値：Pico にジャンパ線を挿したときの高さ、ベルトの幅、ESC とモーターの取付穴のピッチ

## ターン 3

試験ファームを作りました。作業フォルダーの `esc_test.py` です（MicroPython 用）。言語の指定がなかったので、USB からすぐ書き換えられる MicroPython にしました。C/C++ SDK がよければ書き直します。

### 動作
- 50Hz の PWM を出し、**1000µs = 停止、上限 1100µs**。プログラム内で 1100µs を超える値は出ないように切り詰めています。
- 起動後 3 秒間は 1000µs を出し続けて ESC をアームさせます（LED が速く点滅）。
- **GP16 のジャンパを GND につなぐと**、2 秒かけて 1100µs まで上げて回します。**外すとすぐ 1000µs** に戻ります。
- 誤って回らないように、**起動時にジャンパが GND につながっていたら、一度外すまで回しません**（LED がゆっくり点滅）。
- ジャンパの判定は 3 回連続（約 60ms）で GND のときだけオンにしています（接触のばたつき対策）。
- Ctrl-C や例外で止まったときも、最後に 1000µs に戻します。

### 配線
| Pico W | 接続先 |
|---|---|
| GP2 | ESC の M1 信号 |
| GND | ESC の GND（必ず共通） |
| GP16 | ジャンパ（GND につなぐと回る） |

ピン番号はファイル先頭の定数で変えられます。

### 試験の前に確認してほしいこと
1. **ESC が PWM 信号を受け付けるか**：これが一番の不確定要素です。HAKRC の 4in1 ESC は BLHeli_S 系のことが多く、BLHeli_S なら通常の PWM（1000〜2000µs）を受け付けるはずです。ただし **Bluejay に書き換えられていると DShot しか受け付けず、PWM では回りません**。お手持ちの ESC のファームウェアは、BLHeliSuite などで確認できます（確認方法は調べます）。
2. **1100µs で回るとは限りません**：ESC の設定（スロットルの最小値や起動パワー）によっては、1100µs ではまだ回らない、あるいはピクッと動くだけのことがあります。回らなくても故障とは限らないので、その場合は結果を教えてください。上限を上げるのは、その結果を見てから一緒に決めましょう。
3. **電源**：この試験では Pico は **USB だけ**で給電し、MINI360 は VSYS につながないでください（前回の USB と VSYS の同時給電の問題を避けるため）。ESC は 2S 電池から給電し、GND だけ Pico と共通にします。
4. **プロペラなし**で、モーターはクランプやテープで机に固定してください。固定しないとモーターが跳ねて線が引っ張られます。

### 使い方
1. Thonny などで `esc_test.py` を Pico に保存します。**ファイル名は `main.py` にしない**でください。`main.py` にすると電源を入れただけで自動で動き出します。
2. ジャンパを外した状態で、ESC に電池をつなぎます（ESC の起動音が鳴るはずです）。
3. Thonny から `esc_test.py` を実行します。「準備完了」と表示されたら、ジャンパを GND につなぎます。
4. 止めるときはジャンパを外す → Thonny の停止ボタン → 電池を外す、の順にしてください。

### 注意
- Thonny の停止やソフトリセットのあと、PWM の出力がどうなるか（最後の値のまま残るか）は私の手元では確認できていません。プログラムは終了時に 1000µs に戻すようにしていますが、念のため**作業の前には電池を外す**習慣にしてください。
- 私はこのコードを実機で動かしていません。最初はモーターを固定して、すぐ電池を抜ける状態で試してください。

電池は**下に吊るす**配置にしました。ピン上向きの MPU-6050・MINI360 と、高い位置の Pico とぶつからないようにするためです。

### 寸法の扱い
**仮の値（実測してください）**
- プロペラ直径：2.5 インチ（63.5mm）と仮定
- モーター取付穴：直径 9mm の円上に 4 個、M2 と仮定
- ESC 取付穴：20×20mm、M3 と仮定（16×16 の可能性もあり）
- Pico の柱の高さ：30mm（ピン＋ジャンパ端子＋線の曲げ代の仮定）
- MPU-6050 の基板寸法と穴位置、MINI360 の基板寸法、電池の幅、ベルトの幅と厚み

**データシート由来の値（念のため再確認）**
- Pico W：基板 51×21mm、取付穴 47×11.4mm

### 設計の考え方
- **モーターの位置は自動計算**にしました。上から見てプロペラの円が本体板から 6mm 以上離れる位置を求めています。Pico を柱で高い位置に付けるので、プロペラが本体の上を通る配置は避けました。
- その結果、仮の値のままだとモーター対角の距離が **約 175mm** になります（計算値。OpenSCAD のコンソールに表示されます）。Pico W の基板が 51mm と長いので本体が大きくなり、1104・2S の機体としては大きめです。重くなると飛ばない可能性があるので、これは気になる点です。
  - 小さくしたい場合の案：プロペラが本体の上を通るのを許して、高さで逃がす（Pico の柱を低くする、など）。ただし、ジャンパ線がプロペラに当たる危険が増えます。
- アームは厚さ 4mm、幅 8mm の PLA です。強度は実物で試すまで分からないので、最初の 1 台は割れたら太くする前提で考えてください。
- MPU-6050 は機体の中心から少し離れています（後ろ寄りの左）。ホバリングの試作では大きな問題にはならないと思いますが、気になれば位置を変えられます。

### 印刷前にやってほしいこと
1. OpenSCAD で `frame.scad` を開いて F5 でプレビューし、部品の外形（半透明）との重なりを見る。
2. [A] の仮の値を実物の測定値に書き換える。特に、**ESC とモーターの取付穴ピッチ、プロペラ直径、Pico にジャンパ線を挿したときの下側の高さ**。
3. 本番の前に、モーター台 1 つと ESC の穴だけを薄く印刷して、穴が合うか確かめると、刷り直しが減ります。

測った値を教えてもらえれば、こちらで書き換えます。また、機体の大きさ（約 175mm）が気になるようなら、小さくする案で作り直します。
